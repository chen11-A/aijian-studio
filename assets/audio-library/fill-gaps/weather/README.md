# 真实天气录音补充

这里的 8 条音频来自 8 个独立录音条目，不是用同一短片复制或切段凑数。原始页面分别确认 CC0、作者、编号、真实录音说明和技术参数。每条 `*-source.json` 保存原始页面链接、简短许可原文、核实日期以及文件匹配依据。

下载来源为 QuietField v1.8.1 的公开 GitHub 发布包（只提取 WAV，不运行软件）。录音文件 SHA256 与其固定提交 `1b54955db94baa59571bb0ae3e56fcad190f2087` 的 `src/catalog.public.json` 一致。原站编号、作者、声道、采样率及向上取整时长与目录一致。原站没有公布文件哈希，因此不能声称完成原站文件逐字节比对。

- 1019：露台夏雨；1290：雨落水洼；1289：雨落水泥。
- 1295：车内录到的雨打挡风玻璃，不能当作房屋窗户录音。
- 2679：伞下录到的雨声，作者 Pierre SIBANARCO；不是雨伞开合。
- 0904：森林树梢风；0908：高草丛风；0907：乡间灌木风。
- 除 2679 外，作者均为 Joseph SARDIN。

处理为 48kHz 单声道 OGG，截取最长 45.5 秒原录音，再做 0.5 秒尾首交叉淡化，输出 45 秒；伞下原录音较短，输出约 30.74 秒。优先保证最终有损文件真峰值与采样峰值 ≤ -1 dB，因此部分积分响度低于 -20 LUFS。每条测量和接缝报告见同名 JSON。客观接缝检查不等同人工试听，本轮未人工试听。

`entries.json` 是待整合条目，本目录不修改主 manifest。

## 离线重建脚本

`rebuild.py` 收录实际使用的处理顺序；共用 `../weather/rebuild_common.py` 和素材库根目录 `loop_tools.py`。输入目录放置 1019.wav、1290.wav、1289.wav、1295.wav、2679.wav、0904.wav、0908.wav、0907.wav，均须与本目录来源证据的 SHA256 一致。

```sh
python3 rebuild.py --ffmpeg "/绝对路径/ffmpeg" --ffprobe "/绝对路径/ffprobe" --input-dir "/本地原录音 中文" --output-dir "/新的构建输出"
```

Windows 可将程序路径改成 `C:\工具 目录\ffmpeg.exe`、`C:\工具 目录\ffprobe.exe`，使用 `python` 运行。程序参数用独立数组传给子进程，不经 shell；支持中文和空格。输出目录必须尚不存在；不写现有音频、entries 或主 manifest。新目录产生 OGG 与最终实测 JSON。遇原录音哈希不符、格式、峰值或接缝不合格即失败。

这里的“可复现”指使用已保存校验值的原音频和同一处理步骤重建并实测验证；原始文件需事先合法取得，本脚本不联网。Vorbis 的随机流编号以及 ffmpeg/编码器版本可能使输出文件 SHA256 不同，不承诺跨版本逐字节一致。新增脚本本次仅做语法和命令行检查，没有重新转码已锁定音频。
