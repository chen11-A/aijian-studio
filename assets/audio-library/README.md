# AIVORA 本地 CC0 音频素材库

当前清单 **176 个音效、31 个配乐文件**，其中配乐是 **22 首独立作品＋9 个原曲的另行循环派生版**，不能把派生版计为新增曲目。每条 `manifest.json` 都记录 `author`、具体 `source`、许可证、用途、时长、实测响度、真峰值、采样峰值及 SHA-256。所有处理在本地运行。

## 使用和验收

```sh
python3 assets/audio-library/check.py --ffmpeg /usr/bin/ffmpeg --ffprobe /usr/bin/ffprobe
python3 assets/audio-library/check.py --ffmpeg /usr/bin/ffmpeg --ffprobe /usr/bin/ffprobe --strict-request
python3 -m unittest discover -s assets/audio-library -p 'test_*.py'
```

FFmpeg/ffprobe 必须使用完整路径；可含中文和空格。默认检查验证现有文件的采样率、声道、时长、许可证字段、作者、校验值、响度和两个峰值，可循环条目还逐声道实测接缝。`--strict-request` 额外检查第二轮的类别数量、真实雨风、环境与音乐循环等；仍有素材缺项时返回非零，不能把常规通过当作全部需求已满足。

## 第三轮响度与峰值要求

全部48kHz Ogg Vorbis；音效单声道、配乐双声道。音效实测范围必须为 **−21至−15 LUFS**，配乐 **−22至−18 LUFS**；`peakLimited` 不再豁免范围。只有不足400毫秒且无法测得积分响度、附中文说明的短音可保留`null`，峰值仍必须检查。

现有187条中79条重新处理：增加增益、四倍过采样动态限幅、回到48kHz并编码，随后重新测量。循环输入重复三遍处理，取中间原长度的一遍，并实测最终接缝。动态限幅会改变瞬态和动态范围；不再沿用第二轮只衰减、不提高短音响度的策略。真峰值≤−1 dBTP，采样峰值≤−1 dBFS。完整前后数据和脚本见 `ROUND3_NORMALIZATION.json`、`normalization/`。

用户提供固定提交原件后，已恢复并整合21条新素材，第三轮完成时208条，第四轮删除1个重叠文件后现共207条。详见 [第三轮整合清单](round3/README.md)，所有来源、作者、原件校验与处理记录齐全；未导入_raw目录。响度处理不等于人工试听。

基线129个文件实测62个采样峰值超过0dBFS，最高+15.332722dBFS；80个超过-1阈值的文件重新衰减编码。这些历史处理逐条记在 `PEAK_REPAIR.json`；其中部分文件后来按用户要求删除，最终库峰值以最新 `VALIDATION.json` 为准。方法见 [PEAK_SAFETY.md](PEAK_SAFETY.md)。
