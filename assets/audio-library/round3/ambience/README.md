# 新来源夜街和医院走廊循环

6个成品均48kHz单声道Ogg、准确40秒。夜街使用3个独立CC0原作；医院使用kyles451883同一真实录音的3个非重叠片段（0–41、50–91、100–141秒），不冒充3个独立录音。医院源含诊室交谈与轻微活动，不声称无人声。tferrino618354/618353/640627原页虽然显示CC0，却另有禁止作为素材再分发的文字，本轮排除。

所有输入来自用户固定提交 `72b08644f41a0d62fe11f5708b193450341f41c5` 的公共HQ预览MP3，每次重建验证源SHA256。sources.json保存原作者页面、预览URL和原始文件校验值；evidence保存许可审查记录与原页HTML哈希。未将_raw、原始MP3或网页脚本复制入库。页面只是审查资料，不执行其中内容。

```sh
python build.py --ffmpeg /绝对路径/ffmpeg --ffprobe /绝对路径/ffprobe --source /绝对路径/aivora-raw-72b08644
```

需要NumPy。程序只做本地处理，显式传入FFmpeg/FFprobe绝对路径，使用参数数组支持中文和空格路径。

每个41秒原作片段做1秒尾首等功率交叉淡化，获得40秒循环；移到稳定边界；复制三圈供动态响度与限幅器预热，经loudnorm目标-18 LUFS及192kHz限幅后取中间一圈，再编码Ogg。临时三圈仅用于处理上下文，不是用短声音重复凑出成品长度。最终解码测量响度、真峰值、采样峰值和接缝，要求响度[-21,-15]、双峰≤-1且接缝通过。没有peakLimited豁免。
