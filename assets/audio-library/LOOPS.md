# 真实录音交叉淡化循环

`loop_tools.py` 只使用 Python 标准库和调用方提供的 ffmpeg 完整路径。保留源文件，输出新 OGG 和测量报告，不修改 manifest。`loop_entries.json` 提供雨、风两个派生条目，来源和许可证沿用原录音，增加处理说明与报告路径。

```sh
python loop_tools.py --ffmpeg /usr/bin/ffmpeg --input "sfx/真实 录音.ogg" --output "loops/新的循环.ogg" --report "loops/新的循环.json" --crossfade 0.5 --target -20
python -m unittest test_loop_tools.py
```

Windows 将 ffmpeg 参数替换为实际完整路径，如 `C:\工具 目录\ffmpeg.exe`。通过参数数组启动，不经过 shell。默认解码为 48kHz 单声道，保留中段，将最后与最前 0.5 秒等功率重叠淡化；短录音的重叠限制为长度的四分之一。新的文件边界位于原录音相邻采样处，交叉淡化在文件内部完成。没有把首尾压成静音。输出比输入短一个交叉淡化时长，雨约 5.26 秒、风约 1.61 秒；这是短录音循环，长铺底可能听出重复，不宣称长环境录音。

固定增益校准到约 -20 LUFS。预测过高峰值时采用无状态 tanh 柔性限幅，再校准响度；无状态处理不会引入压缩器启动状态或破坏周期。雨声采用此处理；风声无需。所有报告都来自最终 OGG 再解码的样本与实际 loudnorm 测量。真峰值要求不高于 -1 dBTP，响度误差不超过 0.5 LU。

接缝客观检查包括：末采样到首采样跳变、不跨边界的相邻采样差分第 95/99 百分位、跳变百分位、接缝每侧 20 毫秒 RMS、附近区域 RMS、左右 RMS 比。要求边界跳变不超过全片相邻差分第 99 百分位，接缝/附近和左/右 RMS 比均在 0.5–2。输出失败时保留报告且返回非零退出码，不能据此标记可循环。客观检查不能证明所有播放器都无缝，也不等同主观试听；本次没有完成主观试听。播放端须准确连续重复解码样本，不得自行加间隙。
