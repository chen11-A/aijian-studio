# 真实录音交叉淡化循环

`loop_tools.py` 是只使用 Python 标准库和调用方显式 FFmpeg 路径的**单声道**循环处理工具，保留源文件，输出新 OGG 和测量报告，不修改 manifest。它不会保留立体声音乐，音乐请使用 `round2-loops/build_loops.py` 的双声道处理及逐声道验证流程，详见该目录 README。

`loop_entries.json` 现在保存两个实际交付的 40 秒环境循环示例：通风口、浴室风扇。它们分别来自 Benjamin Burnes 的两个独立真实设备录音，原始长度均超过 30 秒，不是把短采样不断重复凑成长录音。测试读取示例所指的 `round2-loops/` 音频和报告并重新解码校验。主清单包含完整的 8 个设备环境循环和 9 种情绪音乐循环。

```sh
python loop_tools.py --ffmpeg /usr/bin/ffmpeg --input "sfx/真实 录音.ogg" --output "新循环.ogg" --report "新循环.json" --crossfade 0.5 --target -20
python -m unittest test_loop_tools.py
```

Windows 将 ffmpeg 参数替换为实际完整路径，如 `C:\工具 目录\ffmpeg.exe`。通过参数数组启动，不经过 shell。旧单声道工具解码为 48kHz，保留中段，将最后与最前 0.5 秒等功率重叠淡化；短录音的重叠限制为长度的四分之一。新的文件边界位于原录音相邻采样处，交叉淡化在文件内部完成，不把首尾压成静音。生成的时长比输入短一个交叉淡化时长，工具本身不会替短源录音补足时长。

新交付循环使用第二轮工具：选择真实连续长片段、交叉淡化、稳定窗口旋转、固定增益及最终 OGG 复测；以峰值安全优先，必要时允许响度低于 -20 LUFS，详细数值和标记见每份报告。音乐保持立体声并逐声道验证。

客观检查包括末首采样跳变、相邻差分第 99 百分位、接缝每侧 20 毫秒 RMS、附近区域 RMS、左右时间窗 RMS 比。边界跳变不超过全片相邻差分第 99 百分位，接缝/附近和前后 RMS 比均在 0.5–2。**未完成人工试听**，客观检查不等同乐句、和声和主观音质验收；播放器也需要连续重复解码样本而不自行插入间隙。

旧雨声、风声短采样和它们的派生循环已从交付中移除，对应旧报告同步删除，历史记录见 `ROUND2_CHANGES.md`。不得用短雨风采样或设备声冒充完整自然环境覆盖；当前八个环境循环主要为设备/建筑环境，尚缺所需自然和公共空间类别。悲伤音乐目前仅一个独立作品，仍缺两首。
