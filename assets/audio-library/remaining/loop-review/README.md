# 循环接缝复核与本地试听

双击 `index.html`，播放原始 Ogg，或点击「从尾部两秒开始循环」。播放器已开启循环。页面和音频均使用本地相对路径，不联网，不生成额外音频。浏览器循环衔接受播放器影响，不能将播放间隙直接判定为文件接缝问题。

`metrics.json` 保存清单快照哈希、每个原始 Ogg 文件哈希及每声道客观指标。检查先把原始音频解码为 48 kHz 浮点采样，保持原声道数；边界相邻样本跳变须不超过整段相邻差分第 99 百分位，边界与附近、左右各 20 毫秒窗口的 RMS 比须在 0.5–2 之间。

客观指标直接来自原 Ogg 浮点解码。人工试听应留意节拍、乐句、环境事件和音色突变；这些问题不一定能由数值阈值发现。

**未进行人工试听。** 当前工具不能完成可靠的听觉审查，客观检查通过不代表听感已验收。`subjectiveListeningPerformed` 固定记录为 `false`。

重新生成（必须显式提供工具绝对路径，支持路径含中文和空格）：

```bash
python review.py --ffmpeg /usr/bin/ffmpeg --ffprobe /usr/bin/ffprobe
```

脚本只写本目录，读取清单中全部 `loopable` 音频，不修改主清单或原音频。报告反映生成时清单快照；后续新增或变更循环素材应重新生成。
