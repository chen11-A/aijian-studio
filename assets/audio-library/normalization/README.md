# 第三轮素材响度统一

音效目标 −18 LUFS，实际允许 −21 至 −15 LUFS；配乐目标 −20 LUFS，允许 −22 至 −18 LUFS。`peakLimited` 不再豁免响度范围。只有不足 400 毫秒、实测积分响度为不可测且附中文说明的短音可以保留 `null`。所有素材真峰值、采样峰值均须不高于 −1。

`snapshot.json` 保存本次处理前的 187 条清单。脚本仅处理这些路径，不修改主清单，也不处理其他代理新增的素材。`ROUND3_NORMALIZATION.json` 保存每条处理前后的实测响度、峰值、最终哈希、时长和逐次增益参数，供主任务合并元数据。

处理顺序：先按目标响度增加增益，在 192 kHz（四倍过采样）使用 `alimiter` 动态限幅，再回到 48 kHz 并编码 Ogg Vorbis。限幅初始幅度上限 0.70，预留编码峰值余量。每次编码后重新用 `loudnorm` 读取输入积分响度/真峰值，用 `astats` 测量实际浮点解码采样峰值；不合格时调整增益和上限并重试，最多 12 次。

循环素材重复输入三遍，让限幅器在边界前后持续工作；处理后按原始解码帧数仅截取中间完整一遍，保持时长与内容。最终编码后逐声道检查首尾跳变和短窗口 RMS，不通过就保留原文件并报错。**这些是客观测量，不是人工试听；动态限幅会改变瞬态和动态范围。**

本轮先试验纸页翻动1与森林循环，保存 `TRIAL.json`，通过后批量处理。79 条实际修改，16 条受处理循环通过接缝；5 条不可测短音保留。SFX 实测范围 −20.98 至 −17.95 LUFS，配乐 −21.75 至 −19.96 LUFS；最高真峰值 −1.05 dBTP，最高采样峰值 −1.052554 dBFS。

运行（显式提供工具绝对路径）：

```bash
python normalization/normalize.py --ffmpeg /usr/bin/ffmpeg --ffprobe /usr/bin/ffprobe --ids sfx-9dcf180a63dd r2-loop-bsb-2713
python normalization/normalize.py --ffmpeg /usr/bin/ffmpeg --ffprobe /usr/bin/ffprobe --apply
```

不带 `--apply` 只做试验，不覆盖原音频。快照中的源路径日后可能由主任务替换，此时应重新准备快照，不能盲目复用旧路径。报告是本轮处理证据，不应重复运行覆盖历史记录。

医院等低音量环境素材同样按音效标准保存；环境混音需要约 −30 LUFS 时，应在选择器/时间线额外施加约 −12 dB 增益。最终混音响度仍需测量，不能仅以素材标签推断。
