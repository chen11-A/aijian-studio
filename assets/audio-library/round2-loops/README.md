# 第二轮长循环派生

本目录只从素材库已有、具有 CC0 来源证据的真实文件制作派生循环，不修改原音频或主清单。`entries.json` 供主清单整合；每个 `.ogg` 有同名 `.json` 客观测量报告。全部 48kHz Ogg Vorbis，环境单声道、音乐保留双声道。

## 内容与来源

- 音乐：原有九类情绪各选一个独立作品，作者 **effacestudios**；每条沿用原作品的固定提交来源链接和 CC0-1.0 许可。原授权证据在上级 `licenses/effacestudios-CC0.txt`。
- 环境：**Benjamin Burnes** 的 Fans and Drones 实录包，分别取通风口、浴室风扇、电脑风扇、除湿机、微波炉、室外空调、室外底噪、水槽龙头。每条来自不同的原始录音，截取约 41 秒、交叉淡化后为 40 秒，不使用一秒素材不断重复凑长。每条沿用原固定提交来源链接和 CC0-1.0 许可；原包许可证据保存在上级 `licenses/`。
- 声明：上述八个环境主要是室内/建筑设备环境，**不代表**雨、海浪、森林、街道等自然和公共空间环境均已覆盖。

## 可复现处理

需要 Python 3、NumPy 和支持 Vorbis 的 FFmpeg；脚本本身不联网、不自动安装依赖。显式传入工具绝对路径，不查询 PATH。

```sh
python3 assets/audio-library/round2-loops/build_loops.py --ffmpeg /usr/bin/ffmpeg
```

Windows 可使用 `--ffmpeg "C:\视频工具\ffmpeg.exe"`。源路径、输出路径通过参数数组传入，不通过 shell，支持中文和空格。脚本读取上级 manifest，按原条目 ID 和情绪选择输入；会覆盖本目录同名派生文件及报告，不修改上级原音频及 manifest。

处理为：解码 → 选择真实连续片段 → 尾首等功率交叉淡化 → 循环边界旋转至稳定窗口 → 固定增益 → Ogg 编码 → 最终文件再次解码与真实 loudnorm 测量。音乐保留立体声；使用能量上升包络的自相关估计拍速并选整拍长度候选，但**不声称**自动识别乐句与和声。旋转后的输出长度在 30–60 秒内。没有将首尾淡到零以掩盖接缝。

以 -20 LUFS 为增益目标，但真峰值和采样峰值均不高于 -1 dB 为更高优先级。高峰均比音乐允许响度低于目标；报告 `peakSafetyPrioritized` 明确标记。未使用会改变动态音色的强限幅来强行追响度。

## 验证与缺项

每声道检查最终解码后的末首采样跳变不超过相邻差分第 99 百分位，接缝两侧 20ms RMS 比与接缝/附近 RMS 比均在 0.5–2 之间；保存真实响度、真峰值、采样峰值、时长及输入/输出 SHA-256。只有这些客观检查全部通过才导出 `loopable: true`。

这些数据只支持“音频边界没有明显数值断点”，不能证明节奏、乐句、和声或各种播放器均无缝。**未完成人工试听**，报告统一标记 `subjectiveListeningCompleted: false`，音乐循环仍需主观验收。

悲伤类别目前只有原有的《局外人》一个独立作品，仍缺另外两首；没有把同曲不同段算作新曲，也没有把未经试听的其他情绪曲目直接改标悲伤。自然环境覆盖缺项另见上级来源研究与报告。
