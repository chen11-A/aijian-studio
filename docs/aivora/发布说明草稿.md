# AIVORA 桌面版发布说明（草稿，6-2）

> 草稿，合并会话 2026-11-06 起草。版本号、安装包 SHA256、「已经能用」一节要在 6-1 交付包定下来以后按实测结果改。「还没做成的」一节以 `docs/aivora/持续开发方案.md` 第 3 批的核对为准（2026-11-06），后端做完一条就从这里删一条。

## 这是什么

AIVORA 是在自己电脑上运行的 AI 短剧 / 漫剧制作软件：贴进小说或剧本，软件分场、拆镜头、定角色样子、出画面和视频、配音、配字幕，最后在剪辑页拼成成片导出。生成画面、视频和配音用的是你自己的 Grok 会员账号，作品和素材都存在你自己的电脑上。

支持 Windows（安装向导）和 Linux。

## 已经能用的（待 6-1 实测后核对）

- 从小说到分场剧本、导演拆镜头，镜头数和台词按原文核对，漏拍的结尾会提示。
- 角色和场景定妆照，生成时带上参考图。
- 每个镜头出起始画面和视频，可以出多个版本挑一个。
- 多角色配音，镜头长度按配音长度定。
- 剪辑页时间线：缩放、快捷键（J/K/L、方向键）、剪掉、拖动换位置、多选、撤销。
- 导出：清晰度、字幕（烧进画面 / 单独 .srt / 不要）、字幕样式、封面、标「AI 生成」；旧镜头可以补做不带字幕的版本，不花额度。
- 横屏 16:9、竖屏 9:16，或两种都要。

## 已知限制

AI 视频本身做不好的，软件也没办法保证：

- **复杂扭打**：两人以上贴身缠斗、抱摔、连续攻防，动作容易乱、肢体穿插。简单的挥拳、格挡、追打效果好一些。
- **手指细节**：手指数量、握物姿势、弹琴打字一类的特写容易出错。
- **超过 10 秒的长镜头**：一个视频越长越容易走样，人脸和背景会慢慢变。台词超过 15 秒的镜头不会生成，要分成两个镜头。
- **3 人以上同框**：同一画面里人越多，越容易认错人、脸不一致。

## 还没做成的

下面这些在计划里，但这一版还没有，或只做了一部分：

| 能力             | 这一版的情况                                                               |
| ---------------- | -------------------------------------------------------------------------- |
| 环境音和音效     | 只写了文字说明，成片里还没有雨声、脚步声这类声音；视频自带的声音是关掉的   |
| 四层声音混合     | 只有配音响度统一、配乐给人声让位；环境音和音效还没混进去，整片响度还没统一 |
| 长台词自动拆镜   | 台词超过 15 秒会报错，要自己分到两个镜头                                   |
| 自动粗剪         | 一键成片最后会把各镜拼起来，但不会按台词剪掉头尾                           |
| 局部重做         | 界面能选一段，但实际只能整镜重做；改写和延长视频还不能用                   |
| 口型同步         | 没做，说话镜头的嘴型和配音对不上                                           |
| 审片看图打分     | 审片只看文字，不能看画面打分、自动挑版本                                   |
| 中英文提示词对比 | 没做，生成一律用中文描述                                                   |

## 需要准备什么

- Grok 会员账号（生成画面、视频、配音都用它）。
- Windows 10/11 64 位，或 Linux 64 位；建议预留 10 GB 以上空间放作品。
- Windows 安装包自带 FFmpeg 和中文字体，不用另装（待 4B-B02 在没装 FFmpeg 的电脑上实测确认）。
