# AIVORA 桌面版发布说明（草稿，6-2）

2026-11-07 更新。本稿按云端开发分支产品合并ab11a61（候选84c44b2）及独立后续功能分支的实际范围整理，尚未对应新安装包，不能把下述内容当作已有安装包的承诺。发布前须补版本号、实际安装包SHA256和Windows安装/会员端到端验收；当前进度见[进度看板](当前进度.md)。

## 当前开发分支已有的功能

- 从小说或剧本分场、拆镜头，检查原文覆盖、台词和场记提醒；整理七段视频说明后比较并明确确认。
- 人物、场景和镜头素材保留版本；生成前核对范围、秒数、声音与预计视频数量。
- 对白、环境音、音效、配乐四轨共用混音安排，支持片段音量、淡入淡出、整轨静音及可选最终响度整理。试听与最终完整观看仍需实际核对。
- 本地声音库可单条加入，或查看本镜建议后明确选择完整轨道；已有声音保留，整组可安全移除引用。安排时间属于创作计划，不保证实际动作已对齐。
- 长对白提供完整句拆镜审核，接受时保留原版历史与已有媒体；新镜头仍需重新确认生成范围和声音长度，不自动重复花费额度。
- 原版单镜内1–10秒的画面局部重做保留原音轨和旧版；跨镜、来源无法核验及新拼接版不冒充支持。
- 持久历史、批量前备份、退出保存保护与工程包恢复。工程包保存当前集与引用媒体，不携带账号授权、历史库或可复用QC发布权限。
- 导出前由主进程核对实际选版与最终规格文件，显示技术报告后明确发布；进度、停止请求和部分已完成文件分别说明。字幕、封面、横竖画幅按实际选项处理。

## 本批已接入开发分支的粗剪

剪辑页及一键流程共用四轨粗剪，按实际已选视频时长定位和标记范围。声音、响度或字幕阶段未完成时保留可核对的部分文件，流程停下等待处理，不自动检查或发布。缺少本次实际时钟缓存时保留整片播放，按镜跳转/范围标记暂不可用，需要重新合成；缺可靠逐词/动作测量时保持完整片段。

## 使用时需要知道

- 生成能力与额度以实际账号及服务返回为准；软件不显示虚构余额，不按文章中的报价计费。视频时长上限按当前实际能力核对，超限先调整或审核拆镜。
- 复杂扭打、手指与握物细节、多人同框、长时间连续动作和口型属于需要实际观看的风险项，技术检测不能保证效果。
- 当前缺可信逐词或动作实测时码时保留完整片段，不按字幕布局或预计秒数假造剪点。粗剪时码尚未核验时，整片可播放，按镜头跳转和范围标记需重新合成。
- 看图自动评分、中英文生成效果比较及真实口型处理尚无本轮能力验收，界面中的文字审片或口型标记不等于这些能力已验证。
- 原素材、旧版本和已发布的部分文件保留。遇到“保存待核对”先按页面核对结果，不重复提交；遇到“已应用但未保存”先处理保存失败。
- 技术QC、抽帧、完整播放和试听分别验收。发布前仍需完整检查台词、声画、字幕、人物和故事。
