# 3JR 离线捕获回放

工具只读取用户提供的捕获文件，不调用会员接口、不补写导演或动作回复。当前没有收到本轮真实导演/动作原始回复，因此没有真实回放镜头数、挂载数或通过结论。

固定原文为 `packages/aivora-prompts/fixtures/test-novel-2000.txt`，SHA-256 为 `acaba10e8752d4730be1391682a3bbc77e6fd37308e545303dba951c28f31b9e`。工具对文件字节计算 SHA；manifest 必须声明相同值。

## 输入

一个 UTF-8 JSON 文件，结构如下（此处仅为字段说明，不是可运行捕获样例）：

- `sourceSha256`：上面的完整 SHA。
- `captureDeclaration`：`real-capture` 或 `synthetic`。这是提供者的声明，工具不能认证其真实性。
- `scenes`：恰好两项，每项 `sceneNo` 分别为 `1`、`2`。
- 每项 `directorReply`：对应这一场完整、未经手工修写的原始导演回复字符串。
- 第二场必须有 `actionReply`：完整原始动作回复字符串。第一场可选。

每条导演回复仅限该场；不支持的结构、缺失回复、重复场号和哈希不符均明确失败，不补充或猜测数据。

## 执行

仓库根目录运行：

```sh
node apps/studio-web/scripts/replay-3jr.mjs /绝对路径/capture.json /绝对路径/report-new.json
```

输出文件必须不存在。重新运行使用新路径，工具不覆盖历史结果或输入。退出码：`0` 为本次捕获的所有检查通过，`1` 为解析成功但检查不通过，`2` 为输入、加载或读写失败。命令行只打印报告路径、声明及统计，不打印小说、回复、缺失台词或动作文本。

报告包含原文和捕获文件 SHA-256、路径、`captureDeclaration`、`provenance: caller-declared-not-authenticated` 和独立的 `checksPassed`。`real-capture` 不等于通过，也不是真实性认证。

每场统计未压缩解析镜头数与生产默认压缩后镜头数，逐句顺序覆盖、最后一句对白和尾段覆盖情况；第二场另统计动作输入、已分配、未分配数量。检查要求每场至多 16 镜且覆盖通过；第二场恰好输入 19 条动作、至少 17 条已分配、至多 2 条未分配。没有为了凑数删除内容。嵌套导演分块的原始计数逐块使用 `preserveSource=false`，避免生产包装解析器提前合镜；最终结果仍调用默认生产解析路径。

单测回复明确标为 `synthetic`，只验证工具、解析与拒绝边界；不替代真实会员回复回放或成片验收。代码修复后可对同一捕获文件再次执行，用捕获 SHA 确认输入未变。
