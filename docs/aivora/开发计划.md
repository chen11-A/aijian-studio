## 2. 前后端接口约定（两边照这个并行写）

所有数据都存在作品的 `project.json` 里，或通过 `window.aijian.*` 事件推给界面。字段名用英文，界面显示中文。

**C1 任务进度（定妆照、生成画面、生成视频、配音、口型、导出）**

```ts
// 与 Claude 的 next/TaskCenter.tsx 的 TaskItem 一致
type TaskItem = {
  id: string; // 例：scene-2-shot-6-take-1
  shotId?: string; // 界面显示成「第 2 场第 6 个镜头」
  title?: string; // 没有镜头的任务，例：「林晚的定妆照 · 侧面」
  version?: string; // 「A 版」
  kind: "video" | "image" | "voice" | "lipsync" | "export"; // lipsync、export 是新增，GPT 补
  status: "queued" | "running" | "uncertain" | "requeued" | "failed" | "done";
  attempt: number;
  reason?: string; // 白话原因，例：「Grok 拒绝了这张图」
  suggestion?: string;
  waitedSeconds?: number;
};
type BatchProgress = {
  batchId: string;
  label: string;
  done: number;
  total: number;
  failed: number;
  running: boolean;
};
// 事件：window.aijian.onTask(cb: (tasks: TaskItem[], batches: BatchProgress[]) => void)
```

规则：点了按钮 **0.5 秒内**必须有一条 queued 或 running 的任务出现；任何任务最终都要落到 done 或 failed，不能一直转圈。

**C2 导出前检查报告**：沿用 GPT 的 `packages/aivora-qc`（7c0eea5）schemaVersion 1，字段见 Claude 的 `next/qcReport.ts`：`issues[{id,severity:"warn"|"block",time,timeLabel,end,type,message,suggestion,action,detail,scope?}]`。GPT 另外提供 `ShotSpan[] = {id,start,end}`（每个镜头在成片里的起止秒），界面用它把时间换成“第几场第几个镜头”。

**C3 声音四层**（与 `next/volume.ts` 一致）：每场存 `sound = { mood, master: 0–100, lanes: {dialogue,ambience,sfx,score}: 0–100, duckMusic: boolean }`。默认 100/50/70/20，对应 0/−6/−3/−14 dB（换算公式 20×log10(音量/100)）。界面只显示 0–100 的滑块，换算由 GPT 做。

**C4 多选一（版本）**：GPT 把 `FilmTake` 转成 `TakeOption = {id,label:"A 版",status:"ready"|"generating"|"failed",verdict?:"可用"|"建议重做"|"必须重做",notes?,imageUrl?,statusText?}`，并给 `aiChoiceId`（审片选的）和 `selectedId`（用户选的）。新手一键成片：自动采用 AI 选的，标“AI 选的，可换”。

**C5 字幕样式 id（统一）**：最终只用这 4 个 id：

| id       | 界面名   | GPT 要做                                                                                        | Claude 要做               |
| -------- | -------- | ----------------------------------------------------------------------------------------------- | ------------------------- |
| `white`  | 清楚白字 | 不变                                                                                            | 把 `clear` 改名为 `white` |
| `bar`    | 底条字幕 | 不变                                                                                            | `band` → `bar`            |
| `yellow` | 醒目黄字 | 不变                                                                                            | `bold` → `yellow`         |

**C7 提示消息**：后端和逻辑层不再直接给界面写长句。统一返回 `{ code: string, text: string, detail?: string }`，例：`STALL_RETRYING`（“导演一分钟没回话，正在自动重试”）、`EXPORT_DONE_DRAFT`。界面按 `docs/design/copy-zh.md` 把 code 换成最终文案，text 只作兜底。GPT 在 INTEGRATION 里列出所有 code。
