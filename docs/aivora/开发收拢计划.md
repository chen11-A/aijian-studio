1. **冻结开发基线。** 核对开发线包含 `973e746`、`bdd30011`、`4e01b5cf`（媒体路由）与 `03f03b69`（PR `#33`）。本地已验证 `pnpm contracts:check`、`pnpm typecheck:ts`、`uv run mypy`、`uv run ruff check`、前端 5 文件 35 项及桌面非 FFmpeg 锁套件通过；远端推送后需按合并提交重跑完整双平台 `ci.yml`（本地 Ubuntu 24.04 `ffmpeg 6.1.1` 不在 Debian 13 `7.1.5` 哈希白名单内，完整媒体门以 CI 为准）。
2. **先出 Windows 候选，不先发版。** 推送 `aivora/dev` 且 CI 20/20 全绿后，在同一提交上触发 `windows-integrated-installer.yml`（`workflow_dispatch` 非发布 artifact）。用中文和空格路径跑《晚照书店》：全新安装 → 打开旧工程或导入 → 选版与配音 → 导出并试听 MP4 → 覆盖重装读回项目和设置。记录安装包 SHA-256；这轮不调用未经批准的付费服务。
3. **只接入确有用途的新能力。** 优先确认 `1280×800` 布局与 Windows 候选包。继续沿用已支持的模型通道；按生图、视频、配音逐个在特性分支接入 `XAI_API`/外部连接并验证取消、预算拒绝、重试不重复派发、失败不覆盖旧版本。大规模 UI 重写、数据库迁移和后台目录搬迁不阻断首发。
4. **分支清理只出候选清单。** [分支清理准备](分支清理准备.md) 已刷新至 `03f03b69` 基线，覆盖全仓 71 条远程分支（57 条已包含、7 条已取代/只归档、5 条仍有独有改动、2 条保留主干）与 21 个开放 PR，保留完整 SHA、工作流引用与用途；删除前另行确认清单。
