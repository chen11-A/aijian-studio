## 和 GPT 的接口（照这个写 props，GPT 照这个给数据）
- 任务进度：`TaskItem`（和你的 TaskCenter 一致，kind 增加 "lipsync"、"export"）+ `BatchProgress = {batchId,label,done,total,failed,running}`，事件 `window.aijian.onTask`。
- 提示消息：GPT 返回 `{code, text}`，你在 copy-zh.md 里给每个 code 定文案，界面按 code 显示。
- 人物：`gender: "男"|"女"|""`，`ageBand: "儿童"|"少年"|"青年"|"中年"|"老年"|""`。
- 原文覆盖：`coverage = {sceneId, ok, lastLine, missingLines, missingTail}` + 函数 `fixCoverage(sceneId)`。
- 未分配动作：`film.unassignedBeats = [{sceneId, text}]`。
- 导出检查：aivora-qc v1 报告（你的 qcReport.ts）+ `ShotSpan[]`。
- 声音：`sound = {mood, master, lanes:{dialogue,ambience,sfx,score}, duckMusic}`，0–100。
- 版本：`TakeOption` + `aiChoiceId` + `selectedId`。
- 口型：`take.lipSync: "none"|"pending"|"done"|"failed"` + `lipSyncReason`。
- 一键成片步骤：`pipeline.steps = [{id,label,status,done,total}]`。
- 场记提醒：`shot.continuity = [{kind:"missing_look"|"prop"|"gaze"|"axis"|"cut", text}]`。
- **字幕样式 id 统一**：把你 SubtitleStyle 里的 `clear→white`、`band→bar`、`bold→yellow`，`film` 保留（GPT 那边会把 variety 换成 film）。

## 交付格式
1. 分两个 zip 放到共享文件夹 `linux\AIVORA\`：
   - `aivora-ui-3j.zip`：第一部分（会被马上合入 3j）；
   - `aivora-ui-4ab.zip`：第二部分（4a/4b 合入时用）。
   zip 里保持仓库相对路径（如 `apps/studio-web/src/aivora/pro/pro.css`）。
2. 每个 zip 附：SHA-256、文件清单（新增/修改分开，修改的附 diff 行数）、改动说明按编号列。
3. 改了现有文件的，另附一份基于 6efe12d 的补丁（`git diff 6efe12d`），方便 GPT 合并。
4. 测试：tsc、eslint、prettier、vitest（studio-web 全部，附覆盖率）都要过；布局检查 1280×800 和 1920×1080 两个尺寸全页面 0 问题，附截图。
5. 列出“需要 GPT 配合”的清单：每条写清你加了哪个 props、需要什么数据或回调、对应上面哪个接口。
6. 只在 jsdom 里测过的交互，要写明“没有在桌面软件里测过”。
