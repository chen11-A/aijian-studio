## 新票 / 复现票

### R2-U01 · P0 · 横屏作品画面提示词仍写「竖屏构图」

- **现象**：作品 `aspect=16:9`，但三场 48/48 镜的 `directorFramePrompt` / `directorVideoPrompt` 均含「竖屏构图」。
- **验收**：16:9 工程生成的提示词只写横屏/16:9；9:16 工程才写竖屏。
- **负责人**：Claude（导演提示词 / 画幅注入）

### R2-B01 · P1 · 第3场覆盖检查假报警（结尾已拍到仍报 missingTail）

- **现象**：末镜已是阿婆豆浆 +「灯还亮着，就好」，UI/数据仍 `coverage.ok=false`，`missingTail` 为天亮回青石巷整段。
- **验收**：当末句台词已落入某镜 `lines`/`action`/`picture` 时不再报「结尾还没拍到」；或明确区分「末句已覆盖 / 中间叙述镜头不足」。
- **负责人**：Claude（coverage）

### R2-B02 · P1 · 第2场前段串场（仓库场仍写书店门/书架）

- **现象**：`scene-2 码头仓库` 的 no.1–4 `picture`/`action` 仍是撞开书店门、书架；no.5 才进仓库。另 no.5 仍出现「面包车」。
- **验收**：场次 `where`/标题为仓库时，镜头环境不得落回上一场书店；禁止无来源的「面包车」。
- **负责人**：Claude（导演分场/场景锚定）

### R2-B03 · P1 · 导演常报「AI大段没回话」但仍可能出可用草稿

- **现象**：第2场首次两次失败 0 镜；重试出现「大段没回话」却有可用 16 镜草稿。第3场同样告警但草稿可用。耗时长（数分钟级）。
- **验收**：有完整可解析草稿时不弹失败态；超时/截断有明确重试与草稿保留；关键路径导演 P95 < 约定阈值。
- **负责人**：Claude（导演调用/解析）

### R2-B04 · P2 · 配角 ageBand 为空

- **现象**：周烈、打手甲、打手乙 `ageBand==''`；主角与林国栋/阿婆正常。
- **验收**：有对白或动作的具名角色写出年龄段（或显式「不详」策略产品化）。
- **负责人**：Claude

### R2-B05 · P2 · 画面里多出未点名配角（仓库群演）

- **现象**：scene-2 no.7 打斗帧除两名主打外还有多名背景男人；需确认是否来自「打手」设定或幻觉加戏。
- **验收**：镜头 `characters` 名单外的人脸不出现，或自动标为氛围群演并限制数量。
- **负责人**：Claude（画面提示/角色约束）

### R2-B06 · P2 · 「阿婆」定妆/成片呈男性外观

- **现象**：角色设定女/老年/naksh；导出第二镜端豆浆说话者审片呈白发男性外观。
- **验收**：女老年角色定妆与成片性别一致；口型镜头用对应性别音色（naksh）且面容匹配。
- **负责人**：Claude（定妆/角色约束）
