# AIVORA 文档目录（docs/aivora/）

AIVORA 是本地运行的 AI 短剧/漫剧制作软件。这里放计划、任务书和规矩，GPT、Claude 和 Grok 助手都从这里读。文件只在 `aivora/dev` 分支上更新。

## 分工（5 行）

1. 后端会话（`gpt/work-4a`，接手原 GPT）：后端、逻辑、接口、测试、打包。2026-11-06 起合并进 `aivora/dev` 和打 tag 只由「合并」会话做，「总控」会话排任务、看进度，见 开发计划.md「当前任务表」。
2. Claude：全部界面，加内置智能体提示词和界面文案。
3. Grok 助手：审核、用真实 SuperGrok 会员实测、写问题单、最后完整审核、交付 Windows 向导安装包和 SHA256；不改代码。
4. 交叉审核：Claude 看 GPT 的后端，GPT 核对 Claude 的界面接线，Grok 最后装包实测。
5. 不合并 main、不强推；没有用户同意不删分支。
