合并时多做的几件事（都是为了让合并后的 `aivora/dev` 能过 CI，不改模块内容）：

- **收伞3**：删 `assets/audio-library/round3/umbrella/r3-umbrella-close-3.ogg` 和 `manifest.json` 里这一条（207 → 206 条）。模块自带测试「第三轮原件 21 条、每类 3 条」改成 20 条、收伞 2 条（`packages/aivora-modules/audio-picker/library.test.ts`）。`entries.json`、`clips.json`、`MEASUREMENTS.json`、几份 README 里关于收伞3 的历史记录没动，README 里「共 207 条」也没改。
- **aivora-modules 不进 pnpm 工作区**：它自带 npm 的 `package-lock.json`，依赖是 vitest 3、TypeScript 5.8、@types/node 22，和仓库（vitest 4、TypeScript 5.9、@types/node 26）不同。放进工作区要改动全仓锁文件 1286 行、还要放行 esbuild 的安装脚本。先在 `pnpm-workspace.yaml` 里排除，单独用 `npm ci && npx vitest run` 跑。**后端接入时再定**是改成仓库的依赖版本进工作区，还是把要用的函数搬进 `apps/`。
- **Prettier/ESLint 忽略**：`assets/audio-library/` 和 `packages/aivora-modules/` 有 96 个文件没按仓库格式排版、6 个 ESLint 报错，原样合入、加进 `.prettierignore` 和 `eslint.config.mjs` 的忽略列表。后端接入时再统一排版。
- **CI 装中文字体**（`0bf952f1`）：`pnpm test` 会跑 aivora-media 的「隔离系统字体」测试，它默认读 `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`。Linux 测试容器加装 `fonts-noto-cjk`；Windows 上这条本来就跳过。
