# AIVORA 首次使用

这是可双击安装的 Windows x64 桌面版。安装包未做代码签名。Windows SmartScreen 会提示“Windows 已保护你的电脑”或未知发布者。请核对安装包来自本仓库的 GitHub Actions artifact 和同包 SHA256 后再选择仍要运行。不要为了跳过提示去关闭系统安全功能。

电脑上不需要单独安装 Python 或 Node。安装范围是当前用户，不需要管理员权限。

## 安装

1. 从集成构建的 Actions artifact 下载 `AIVORA-Setup-win-x64.exe`（文件名以实际 artifact 为准）和 `SHA256SUMS`。
2. 双击安装包。若 SmartScreen 拦截，使用“更多信息”后仍要运行。
3. 安装完成后，从开始菜单打开 **AIVORA Dev Core**。工作区在 `%APPDATA%\AIVORA Dev Core\workspace`。

## 登录 SuperGrok / ChatGPT

1. 首次进入会看到连接方式。选 **用 SuperGrok / X Premium+ 账号登录**，或选 ChatGPT 官方账号。
2. 在系统浏览器里完成授权。Grok 的回调是本机 `http://127.0.0.1:56121/callback`。令牌只留在本机安全存储里，不会出现在页面上，也不会写入作品数据库。
3. 如果授权页提示这个回调地址不被允许，登录会停在这一步，不会读取浏览器 Cookie，也不会反复弹窗。点 **改用 API Key（高级备用）** 即可。公开的 OIDC 文档没有列出这个回调，所以这是已知风险。
4. 登录成功后，到模型中心选择文本模型。

### 登录成功但推理返回 403

Hermes 文档说明：部分普通 SuperGrok 订阅可以登录成功，推理接口仍返回 403。这时页面会用中文说明这次没有生成结果，并给出 **改用 API Key（高级备用）**。点这一下就会打开 API Key 输入，不需要反复登录。

API Key 是按量备用路径，会走作品预算门。还没设置作品预算时，按量调用会被挡住，并提示先设置作品预算。SuperGrok / ChatGPT 登录派发不进货币预算门，但每次派发都会写入 `dispatch_billing_records`。

## 开始第一个作品

1. 也可以先选 **暂时离线创作**。
2. 新建作品，选择竖屏或横屏和时长。
3. 在故事或剧本页写入正文并保存。
4. 需要 AI 时再回到 AI 服务，用 SuperGrok / X Premium+ 或 ChatGPT 登录。若推理 403，改用 API Key。
5. 关闭软件再打开，作品仍在本机工作区。

音视频能力使用安装包内的 FFmpeg / FFprobe（开发锁定的 GPL 构建）。卸载只移除程序文件，保留工作区。
