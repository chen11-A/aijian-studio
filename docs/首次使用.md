# AIVORA 首次使用

这是可双击安装的 Windows x64 桌面版。安装包未做代码签名。Windows SmartScreen 会提示“Windows 已保护你的电脑”或未知发布者。请核对安装包来自本仓库的 GitHub Actions artifact 和同包 SHA256 后再选择仍要运行。不要为了跳过提示去关闭系统安全功能。

电脑上不需要单独安装 Python 或 Node。安装向导默认装给当前用户。选择“为所有用户安装”时需要管理员权限。

## 安装

1. 从集成构建的 Actions artifact 下载 `AIVORA-Setup-0.2.2-win-x64.exe` 和 `SHA256SUMS`。
2. 双击安装包。若 SmartScreen 拦截，使用“更多信息”后仍要运行。
3. 向导是简体中文，程序名是 AIVORA。可以改安装目录。默认是当前用户的 `%LOCALAPPDATA%\Programs\AIVORA`；这台电脑如果已经装过 0.1.x，默认沿用原来的安装目录。也可以选择为当前用户或所有用户安装，以及是否创建开始菜单和桌面快捷方式。
4. 最后一页的“启动 AIVORA”默认勾选，安装结束后会打开软件。已有登录和作品仍在 `%APPDATA%\AIVORA Dev Core`。安装和卸载都不会删除这个目录。
5. 也可以从开始菜单或桌面的 **AIVORA** 打开。工作区在 `%APPDATA%\AIVORA Dev Core\workspace`。

## 用真实 Grok 账号登录（3 步）

1. 打开 **AIVORA**。还没登录时，第一步就是按钮 **用 Grok 账号登录**。点它，不要再点第二次确认。
2. 系统浏览器打开 xAI 授权页。用 SuperGrok 账号点同意。不要复制代码，也不要在 AIVORA 里输入密码或密钥。
3. 同意后自动回到 AIVORA。页面显示已登录，并列出可用模型。关掉软件再打开，仍然是已登录。

如果授权页拒绝本机回调 `http://127.0.0.1:56121/callback`，应用会自动打开已经带上验证码的链接，并在后台轮询到完成。这一步也不用复制代码。公开的 OIDC 文档没有列出回调地址。2026-10-21 对授权端点的探测：`http://127.0.0.1:<端口>/callback` 会 302 到登录页，`localhost` 主机名和非回环地址会 400。同意之后是否真的跳回本机，要以你这次真实登录为准。被拒绝时不会读取浏览器 Cookie。

同一页的次要按钮是「使用 ChatGPT 账号」。「使用 API Key」和「暂时离线创作」是小字链接。授权仍在系统浏览器里完成。

### 登录失败时界面和日志

失败时页面用中文说明原因，例如：没有同意、授权页拒绝了本机回调、系统浏览器没有打开、安全凭据库不可用、等待超时。不会停在空白页。登录失败和推理 403 都会提示 **改用 API Key（高级备用）**，点一下就到密钥输入框。

日志文件：`%APPDATA%\AIVORA Dev Core\logs\grok-login.log`

里面只有时间、事件名、固定错误码和 HTTP 状态码。不会写入访问令牌、刷新令牌、授权码、验证码或 PKCE。

### 登录成功但推理返回 403

Hermes 文档说明：部分普通 SuperGrok 订阅可以登录成功，推理接口仍返回 403。这时页面会用中文说明这次没有生成结果，并给出 **改用 API Key（高级备用）**。点这一下就会打开 API Key 输入，不需要反复登录。这不是登录失败，日志里的事件是 `sign_in_ok`，错误码是 `ENTITLEMENT_DENIED`。

API Key 是按量备用路径，会走作品预算门。还没设置作品预算时，按量调用会被挡住，并提示先设置作品预算。Grok / ChatGPT 登录派发不进货币预算门，但每次派发都会写入 `dispatch_billing_records`。

## 开始第一个作品

1. 也可以先选 **暂时离线创作**。
2. 新建作品，选择竖屏或横屏和时长。
3. 在故事或剧本页写入正文并保存。
4. 需要 AI 时再回到 AI 服务，用 Grok 账号或 ChatGPT 登录。若推理 403，改用 API Key。
5. 关闭软件再打开，作品仍在本机工作区，Grok 登录也还在。

音视频能力使用安装包内的 FFmpeg / FFprobe（开发锁定的 GPL 构建）。卸载只移除程序文件，保留工作区。
