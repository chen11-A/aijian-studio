# 视频提交失败保护配置界面

实际入口：作品 → 作品设置 → 设置视频提交失败上限。界面只使用本集已有的 `backendProjectId`，不为配置创建 API 作品，不把策略写入 localStorage 或工程正文。未绑定作品、缺少桥能力、读失败均不能提交。

界面不设默认值，只允许明确输入 0–1000 的整数。0 阻止新增视频提交；1000 是技术边界，不是推荐次数或费用承诺。上限仅针对同一输入的 Grok 视频提交失败和未决记录，不是图片、TTS、整条创作链的总预算，也不代替会员和费用门。没有 usage 接口，因此不展示已用或剩余次数。

保存使用真实读取的 revision，单次 CAS。冲突只重新读取一次，保留输入并要求用户再次明确提交；不自动重发 PUT。写入传输失败、结果未确认或回执值不匹配时停用提交，仅允许重新核对。关闭、切工程或 API 作品绑定改变后，旧回复不能更新新会话；关闭窗口不声称取消服务端写入。策略读取和保存不调用生成，也不修改镜头、音轨或已有媒体。

验证使用真实 ProWorkspace 设置入口和受控桥响应，覆盖显式零、无默认/非法整数、冲突刷新、未知写后只读核对、关闭及换工程迟到、缺绑定/缺能力、无效回执。另联合原保存状态、writer 结构卡和只读试片候选回归。此处桥响应是替身，不代表真实账户/API 持久化或视频失败计数已经端到端验收；真实 main/API 消费者由后端独立交付，正常沙箱 Chrome 专项另批进行。

输入身份包括实际首帧与参考图 bytes；重新做图后图像内容变化是另一视频输入，不承诺父级同创作稿整链总上限。本片不提供重启后未知视频任务的恢复或核销界面。
