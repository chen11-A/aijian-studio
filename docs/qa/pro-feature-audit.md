# 真实 Pro 画风差异、音源波形与历史版本浏览器门

入口为 `node apps/studio-web/e2e/pro-feature-audit.mjs`。复用原 QC 门的随机 loopback Vite 生命周期；可用 `--url http://127.0.0.1:5173/`、`--browser /usr/bin/google-chrome`、`--out .aijian-dev/pro-feature-audit`。仅允许本机 HTTP、临时/忽略目录输出，始终启用 Chromium 自身沙箱，不自动安装浏览器、不删除输出目录。

当前范围为六个独立状态 × 1280×800/1920×1080 × 16:9/9:16，共24态；默认 QC32、progress32、core24/full60/url24均保留。每态重新建浏览器上下文，从真实 Pro 页签进入，不使用组件故事页或旧 `.v2` 壳。

| 状态                   | 实际入口与断言                                                                                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| art-style-preview      | 角色与场景 →「请美术定画风」→ 伪 completeText；真实整卡投影只显示画风一个字段，原/建议长文本，确认前风格和人物/素材/版本未改；卡片只有一个确认动作，不盲接全局撤销              |

| waveform-known         | 剪辑页真实 hook → 伪窄 IPC；pending 与错 sourceKey 时不显示，用户刷新后匹配回包才显示256个有限点；5秒已测窗口在20秒片段中只到25%，元数据实际存盘                                |
| waveform-unknown-stale | duration=0 的配乐明确「波形时长未确定」且无波形；真实选择另一视频版本，清旧峰值并拒绝迟到的旧源回包，已有版本保留                                                               |

本范围没有音频 offset/duration 编辑 UI，**不把浏览器选版测试写成裁剪编辑验收**；裁剪、同路径字节变化、真实静音和无音轨由音频纵切已有真实 FFmpeg/文件系统及宿主测试互补。本 QA 已同步完整产品基线 `7494b1d`（含画风、退出保存、波形完整测量校验及历史宿主）；全部正向结果仍以对应提交的普通 Ubuntu CI 为准，不能复用旧提交绿灯。

峰值仅在本 QA 的合成桥中产生，不进入产品默认数据；这里只核对元数据的显示/失效/保存，不实际解码、不写原生文件、不证明听过音频，也不代替 Electron、真实工具锁或最终混音验收。会员状态和文本回复均为伪桥，不登录真实账号，不生成媒体；外部 HTTP 与 `/api` 请求全部阻断且作为失败记录。

每态保留 `feature.png`，确认态另存 `confirmed.png`；`report.json` 含真实导航命中、字段边界、时间比例、调用计数和几何问题，以及提交/脏树与固定源码 SHA256。0要求全部24态通过，1为交互/几何失败，2为配置/环境失败。GitHub注释最多八条，仅固定状态/组合/安全kind/有限几何数值，完整结果留产物；不复制正文、路径或凭据。

本机正向 Chromium 沙箱不可用；本批先核静态与负向，正向必须由普通 Ubuntu runner 的独立调用验证，不能把脚本存在写成24态已通过。

本机已完成四个脚本的 Node 语法、目标 ESLint/Prettier 和 diff 检查；七项 CLI/失败注释负向检查确认缺浏览器为 exit2、零正向且临时服务关闭，原 QC/progress 帮助仍各32态；八项独立合成桥检查核对写读 clone、使用实际 history helper 的全记录哈希、错误哈希拒绝、保存增长、受控失败/PARTIAL及第二集列出。这些均不是24态浏览器正向证据。忽略目录产物为 `.aijian-dev/pro-feature-negative/{report,negative-results,fixture-results}.json`。
