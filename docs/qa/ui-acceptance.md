## 界面审核

第一轮在改布局之前。测量到的问题：

- 1920×1080 到 911×512，AI 服务页的主区域 `scrollHeight` 大于可视高度，但 `overflow` 是 hidden。连接表单、密钥按钮和模型选择在视口外，滚不到。
- 高度不超过 768 的窗口里，左侧导航不滚动。1366×768 上，底部「存储用量尚未接入」盖住「AI 服务」。更矮的窗口里，「素材」「导出」「制作」「审片」被导航容器裁掉。
- 911×512 的设置页，「本地媒体工具 · DRAFT」和标题「用户设置」叠在同一位置（都从 y=100、x=124 开始），标题盖住按钮。
- 720 及更矮的窗口里，设置、用量、声音页同样锁死滚动。

处理：

- 生产工作台的主区域和左侧导航改为可滚动，底部说明不再绝对定位盖住导航项。窄导航的文字改为换行，不再用省略号。
- AI 服务页按内容增高，由页面滚动，不再把表单压进一个不能滚的格子。
- 设置页顶部的媒体工具按钮不再被 flex 压成 0 高度后画到标题上。
- 启动页在矮窗口允许滚动，标题允许换行。首次连接对话框在窄窗口改成单列。

## 两位虚拟用户

### 林可，专业创作者

做过短片，用过可灵、即梦这一类工具。关心三件事：账号是不是官方的、模型是不是自己选的、这一下会不会扣费。

第一轮（改之前，对照当时的页面文字和上面的遮挡）：

- AI 服务页在 1080p 上都滚不到密钥和模型选择。连接这一步是断的。
- Grok 的说明把 OAuth、设备码、`grok login`、SuperGrok 放在密钥框前面，专业用户能看懂，但要点很多次滚动。
- 连上文本模型之后，没有一条短路径去看一次不扣费的演示。
- 新建作品要求「本地工作区」。桌面服务没开时，只能看到一句连接失败，不知道接下来能做什么。
- 预算按钮仍然是禁用的。这是预期：本分支不改预算。

第二轮（改完后，1366×768、1280×720、911×512 都走通）：

1. 进入创作工作台
2. 连接 Grok（API Key）
3. 粘贴一把形状合法的沙箱密钥（这一步是输入，不是点击）
4. 连接 API Key（沙箱）。页面读回「API Key 已登记 · 末四位 0001」，并写明不访问 api.x.ai、不扣费
5. 在模型中心把文本模型选成「Grok 4.7 · xAI 文档目录」
6. 看看媒体沙箱（不产生费用）
7. 沙箱提交

点击 6 次，外加一次粘贴。提交后的状态是 `queued`，原文是「沙箱已排队。没有访问上游，没有预留预算，没有产生费用。」

## Grok 订阅登录

先前写的「xAI 没有公开的第三方 Grok 订阅登录」是错的，已经从界面拿掉。公开流程以这些材料为准：

- [xAI：Grok 订阅可以在 Hermes 里使用](https://x.ai/news/grok-hermes)
- [Hermes 的 xAI Grok OAuth 说明](https://hermes-agent.nousresearch.com/docs/guides/xai-grok-oauth)：浏览器设备码或授权码，授权服务器在 `auth.x.ai`，接口是 `https://api.x.ai/v1`，不需要 `XAI_API_KEY`。有的订阅档位能登录，但推理返回 403。
- 授权端点来自 `https://auth.x.ai/.well-known/openid-configuration`。本应用用和 ChatGPT 一样的本机回调加 PKCE，不用未公开端点，也不读浏览器 Cookie。

第三轮，林可和周宁都走这条登录。浏览器里注入的是模拟 OAuth，不访问 `auth.x.ai`，也不发起付费推理。模拟目录返回 `grok-4.3`，模拟推理返回 403。1366×768、1280×720、911×512 都走通：

1. 进入创作工作台
2. 用 Grok 账号登录
3. 在浏览器中登录 Grok
4. 在模型中心选择「Grok 4.3 · Grok 账号」
5. 检查这次订阅能否推理。页面写出「已经用 Grok 账号登录，但 xAI 返回 403」，并请改用 API Key
6. 看看媒体沙箱（不产生费用）
7. 沙箱提交

每人 7 次点击。沙箱结果仍是本地 `queued`，没有上游，没有费用。

API Key 留在「高级备用」。登录本身不调用 `/v1/responses`。桌面测试用模拟授权服务器覆盖了登录、刷新轮换、退出和推理 403。

文本派发：来源抽取面板在选了 Grok 账号里的文本模型之后，可以用本机令牌直接生成，结果带 `billing_account_kind=grok_login`。令牌不进入服务端。服务端队列里的 `grok_login` 仍会在发出 HTTP 之前失败关闭，因为那边没有这枚令牌。预算和派发判断没有改。

生产界面不再显示「存储用量尚未接入」。

## 仍遗留的问题

- 真实作品、剧集和后续制作请求依赖本地桌面服务。服务没开时，首页仍会写「本地工作区暂时无法读取」。
- 预算按钮保持禁用。预算的保存、预留和派发不在这个分支。
- 模型中心选中的 Grok 文本模型不会出现在视频沙箱的「当前视频模型」上。登录目录里有什么模型，要等真实 `/v1/models` 返回。
- ChatGPT 登录和真实的 Grok 登录都要桌面应用。网页预览只能看到说明。这次没有启动 Electron，也没有打开 `auth.x.ai`。
- 公开 CLI 客户端登记的回调如果不是 `http://127.0.0.1:56121/callback`，真实登录会失败并停在本地，不会改去抓 Cookie。
- 启动页仍有「DESKTOP CREATOR / V2.0」。生产侧栏不再显示「存储用量尚未接入」。
- 依赖已保存作品的编辑抽屉没有在这轮截图里打开。
