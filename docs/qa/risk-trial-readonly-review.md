# 风险试片：只读候选审阅

实际入口为 **作品 → 查看试片候选**。本片按当前分镜顺序列出各场首镜、各场首个有对白镜、多说话人及已有文字／记录待核项的镜头。首镜只是导航代表，不是质量排序，也不声称覆盖全部风险；场级原文缺项及未归属动作仍明确标为场级线索，不编造它们发生在哪一镜。身份或场次记录不能唯一对应时明确未列入，不把后续唯一镜头改称首镜。

候选来自原 `filmPipelineCheckpoint`／`detectDirectorCoverage`／`shotLines` 的文字与记录，不请求供应商、不评画面或听感。详情显示完整当前画面文字、对白与场级检测缺项；只陈述 **显式选版记录**，空、无效、重复分别提示，不采用 `chosenExport`、`takeInUse` 或 pipeline 任一默认回退，也不更改它们。done 只称完成记录；无路径也不证明文件可用。不同生成入口的缺视频统计不作为本页统一选版或提交次数展示。

默认不选条目，选择／展开／刷新／关闭不改工程、不写存储、不持有保存 owner、不生成。明确点击「在分镜查看」才导航至当前仍匹配的场／镜，不调用 `queueBatch` 或打开生成表。原生成前确认、历史、预算和实际派发保持。当前视图只是文字候选，**没有**试片生产输入绑定、生成结果验收或批量放行；这些必须以后沿真实生产契约实现，不能由本页选中或 key 推出授权。

快照 key 只绑定本页真实消费的工程、场／镜文字、明确选版状态及理由，排除 savedAt、directory 和无关作品标题。输入／选版／工程变化使旧导航拒绝；刷新、关闭、卸载均退休旧回调，不让旧回调污染新视图。最后核对与导航在同一同步段完成，无异步授权。相同路径字节未被本片读取／核验，key 也不是文件来源证明。长正文以 React 文本展示，独立容器可滚动，未进行新的像素几何验收。
