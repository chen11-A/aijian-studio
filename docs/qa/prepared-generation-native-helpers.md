# Prepared generation private helpers checkpoint

This checkpoint supplies native-private plan, immutable image-byte snapshots,
lineage projection, and a sidecar facts client. It does not implement or advertise
IPC/preload, the execution factory, video arm/claim, cache verification, continuity
observation, or schema 54 production dispatch. Unsupported adapters must remain
closed before any new provider POST. No provider or member request was made.

The pure runtime now exports the existing pipeline selected-media selector from a
small pure module; the original controller delegates without changing its rules.
The actual compiled CJS request producer is compared with the real editor producer
for reviewed requests before and after queue allocation, including one/three new
versions, preservation of an older selected take, and rejection of creative edits.
There is no duplicate prompt algorithm or repository-source runtime fallback.

The plan separates transient execution/slot locators from original effective input.
Its optional private clientFrame describes the actual normalized client image prompt,
model, aspect and fixed references only when an image POST is needed. A user-fixed
first frame or local continuity extraction does not receive an unused image recipe.
These fields and source byte identities still need the final API 54 producer to bind
them into the existing explicit failure policy; this checkpoint alone is not that
budget consumer and provides no authorization.

The source helper reads only the canonical current episode, shared series media or
stills, or individually owner-verified story media. It retains actual SHA/MIME and
bounded materialized bytes, rechecks aliases and original bytes, and rejects foreign
episodes, late changes, unsupported formats, and oversized images. Story ownership
is checked again during verification. No source path is included in public tables.

The lineage helper accepts only private account/project-scoped API facts, never
project metadata as proof. It restores only proven automatic image/currentness fields
in an ephemeral compiler view; the live record is not rewritten. Automatic reference
fields are projected before the first-frame prompt is checked. The actual built
producer test verifies retained generated frame and location bytes recover the
original request, while a user picture edit retains the new input instead. Full
video-result/continuity and restart consumer validation remain subsequent work.

The private facts client signs the exact raw UTF-8 JSON bytes through the existing
account attestation and fixed loopback routes. It requires exact ACK shapes and
preserves transport/ambiguous writes as WRITE_UNCONFIRMED. Retire may report facts
after an owner leaves; it does not confirm remote cancellation or release UNKNOWN.
The native account lease captures the actual session/bearer and expires on refresh
or expiry, while stable account identity remains unchanged across token refresh.
