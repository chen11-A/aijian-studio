# Actual selected-local-media inspection and NOT_NEEDED contract

`generationSelectedMedia(producer, canonicalRecord, orderedShotIds, host)` accepts the actual closed producer's `pipelineSelectedVideo` and the original `resolveAudioMix` host (verified tools/runner/roots/owner/signal). It returns private role-bound native/visual SHA/path/video-stream-duration snapshots, the exactly pending shot set and `verify(freshCanonical)`. The immutable internal comparison is not writable by mutating the returned projection. Callers must re-read canonical scope/raw hash, invoke verification and apply their final synchronous document/owner/current guard before returning a preparation fact.

The helper reuses original pipeline selection and original native/clean path, episode/shared-media/story ownership, hash-before/after-probe checks. Unrelated audio clips and mix settings are excluded from this read-only media question. A missing/invalid selected file, unknown take, ambiguous done selection, foreign episode, owner rejection or changed source returns SOURCE_UNVERIFIABLE; none is guessed to be a fresh pending generation. Only genuinely absent selected-complete media is pending. The clock must come from the actual video stream, not format/long audio duration. Missing trustworthy stream clocks remain unsupported. No fixed production FPS, CFR, full decode, word alignment, visual inspection or provider success is claimed.

This private OWNED_STREAM_AND_SHA fact is **not** a provider success receipt, a v2 cache verdict, human acceptance or an UNKNOWN reservation release. It performs no API/provider call and writes no media/project/budget data. A readable locally assembled fallback can remain readable without turning its unknown remote attempt into success.

The additive public result is pipeline-only:

```
{ kind: "NOT_NEEDED", projectId, projectHash,
  reason: "LOCAL_SELECTED_MEDIA", selected: [{shotId,takeId}, ...] }
```

No execution ID, provider slot, stage or transferable authorization exists in this variant. Native may return it only for the exact full current ordered pipeline target scope when every required selected source has been verified and final canonical/raw/source checks pass. The renderer may skip unconsumed automatic prerequisites and retain the original review/assembly flow; it cannot infer this result from path strings or top-level SUCCEEDED. Ordinary video runs do not use this variant. Factory/renderer wiring is deliberately left to the owned consumer slice; this checkpoint does not claim pipeline UI support has already shipped.

Actual tests use the source-receipted compiled CJS producer, pinned real FFmpeg/FFprobe and real files. They cover different native/clean clocks at 25/30fps, stale audio isolation, pending versus unknown selections, late bytes/selected take/project changes, exact roots and repeated story-owner verification, a directory alias redirected to a different same-SHA canonical source, and an audio-only MP4 that cannot borrow its format duration as video time. No fake probe metadata, paid request or new generation is used. Targeted six native tests, formal desktop/web types and target lint/format are recorded with the checkpoint. Actual joint main/IPC/packaged use and Windows execution remain for the consumer's fixed-source gate.
