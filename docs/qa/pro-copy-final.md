# Pro 固定提示收尾的消费者核查

本批基线 `912f2cd`。只改软件固定回馈，不以关键词命中数宣称文案表全部完成。

| 实际入口/消费者                                        | 本批处理与边界                                                                                                                                                                                         |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 启动恢复、作品菜单打开 → `setNotice` → 状态栏/任务记录 | 两处中断提示改发原 `WORK_INTERRUPTED`，使用已有中文映射；存档里的中断 reason 和重试行为不变。                                                                                                          |
| 登录 → 浏览器授权                                      | 发原 `AUTH_BROWSER_OPENING`，详情明确授权页的 Grok Build、Allow（允许）及回到软件。成功/取消/失败与账号门槛分支不变，未声称本批验证真实登录。                                                          |
| 编剧/导演/动作/表演建议 → `finishTurn` → 聊天          | `presentNotice` 会保留 raw 的 detail，旧固定兜底确实可见；将“按格式返回/写入”换为“回复用不了/没有修改”。重复用户要求的回复仍拒绝，提供商已给出的有效原因不替换；模型正文、用户文本及提示词不改。       |
| 文本桥无 detail 的失败 → agent 回馈                    | 固定兜底改为“这次没有收到回复”。原 code、提供商原因、重新登录/账号能力/模型不可用分支均保留，未知请求结果不声称没有发送或没有扣费。                                                                    |
| 已确认剧本/分镜或动作/表演 → 原 apply → 保存失败       | 沿用 `SAVE_FAILED`；状态短句仍来自已有中文表，tooltip/任务记录明确“修改已经应用，但还没保存上”。保留原事务、页面/工程完成守卫和媒体；不把应用后的失败说成未修改。                                      |
| 角色页试听                                             | 无 speak 能力时明确该连接不支持试听，不宣称已生成；未登录分支仍独立。已返回音频但播放/读取失败，说明“文件到了，这一页没有播出来”；元数据超时明确已生成但尚未播放。通用失败不显示异常原文或承诺未计费。 |

现有目录保存、退出保存握手、工程包和七段说明的专用状态均不重复修改；全局 notice code、legacy 识别及原 118/106 文案索引不动。`PREVIEW_REASON` 的旧兼容常量仍保留，Pro 当前真实入口已不再使用它。

回归沿原入口检查解析拒绝/重试与错误原因保留、原 Pro 宿主流程，以及现有 action-plan 用例的保存成功/失败两种情形：失败时计划已应用，其他镜头未被分配动作、没有生成视频，状态短句及未保存详情可查。现有试听宿主用例同时检查音频返回后 play 拒绝及 metadata 失败，均不能误报生成失败。不是新造固定文字的镜像测试；最终执行结果以交付日志为准。

仍未覆盖所有旧固定文案。美术/画面说明等其他助手的历史“按格式返回”及特定业务门槛候选留后续逐项追消费者；本批不批量替换。真实会员登录、真实配音及付费请求未调用。
