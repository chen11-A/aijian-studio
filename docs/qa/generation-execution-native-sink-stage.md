# Protected native generation sink stage

This checkpoint implements transient native registry/owner retirement, closed prepare/retire IPC registration and optional protected image/local-frame dispatch routing. Missing protected hooks reject without entering legacy dispatch. It is not the completed API54 factory or an authorization based on issued IDs: trusted canonical/source/ledger verification and required video/cache/local capabilities remain necessary before dispatch.

The image driver delegates to the existing production serializer/downloader/file writer. Only the synchronous final fetch invocation records a POST dispatch. A failed reservation is distinct from a sent request. Any download/byte-read/write exception after POST still calls the private observation adapter and returns WRITE_UNCONFIRMED, never the proven-unsent cleanup. A written image survives an unknown lineage ACK; no automatic retry is introduced.

Controlled regression evidence: `/tmp/generation-execution-still-throws-before.log` has four new failures and five existing passes. `/tmp/generation-execution-still-throws-after.log` has 4 files/33 passes (registry 11, execution IPC 4, library IPC 9, image driver 9). The four cases exercise download rejection, HTTP failure, arrayBuffer failure and a real EISDIR write failure with preserved sentinel bytes. These are fake HTTP plus actual local file operations, not signed API54/Grok/paid generation evidence. Desktop typecheck and owned ESLint/Prettier pass; logs use the generation-execution-native-sink prefix. Original source/helper stages are separate and are not added to this count.
