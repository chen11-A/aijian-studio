## 固定范围

四态 × 1280×800 / 1920×1080 × 16:9 / 9:16 = 16。每态独立上下文，由真实 Pro 的剪辑入口打开“查看本镜声音建议”。使用原六镜/三版工程，另有一条已存在音效；原镜头、版本、定妆和音轨保留。本地合成是明确受控拒绝，仍严格核六镜路径/选版/对白参数及恰一次调用，不当作供应商生成。

| 状态                     | 实际行为与检查                                                                                                                                                                                                      |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| shot-audio-review        | 三轨各两段，六份来源链接、全部淡入淡出/音量变化与十条长提醒/限制；实际时长回执 2.25 秒不采用存档镜长 4 秒；长内容与刷新/关闭可滚动到达；人工查看时原退出 flush 回执 saved。                                         |
| shot-audio-save-guard    | 初始化完成后明确开启保存故障，实际队列预检失败，零 suggest、退出 failed；解除故障后显式刷新成功，退出 saved，不自动添加。                                                                                           |
| shot-audio-pending-stale | 默认首请求即受控挂起；刷新 disabled、关闭可用、读取时退出 saved；关闭后从真实角色页改画风并等实际落盘，释放旧回复不重新开卡、不覆盖新稿；回剪辑页重新查看得到新基线。画风改动的真实重做标记保留，不把它当媒体丢失。 |
| shot-audio-empty-missing | 默认无库；显式刷新依次模拟来源无法核验、轨数上限、无效回复、空计划；每步有限退出、无部分计划，三条空轨及未决定原因完整显示。                                                                                        |

每态先断言真实页与 dialog 已达，再用原几何探针检查溢出、遮挡、内容边界。对动作另做真实可滚区域内的完整可达检查与 trial 点击。没有候选 CSS 注入、force 点穿或放宽阈值。实际操作仅查看/刷新/关闭，旧 add/new apply/导出/生成能力保持 forbidden，零付费派发。

## 替身边界

桥返回完整合成 `SUGGESTED`，元数据取真实 206 条公开目录。固定峰值、声音文件、ZIP、生成媒体都不在本夹具内；原音效路径只是不可执行的占位引用。包络/长说明只验证真实 UI 与 DTO，不代表听过、真文件复制/解码、混音质量、像素动作或语音对齐、Electron 全链路。对应真实 FS/FFmpeg/只读指纹测试仍由产品测试提供。

正常 metadata write 使用原创建夹具的 clone 存读；预检失败需在初始化后明确启用故障，而 pending 首次默认准入无需临时改模式才能挂起。缓存数值保持原始精度，展示取最多四位小数；不从 DOM 重建请求。来源仅 trial 核可点击，不打开外部 HTTP。所有外 HTTP 与 `/api` 请求拦截，实际触发即失败。
