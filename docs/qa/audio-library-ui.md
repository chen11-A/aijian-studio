# 本地音效／配乐入口核对

本批在剪辑页新增“选用本地音效/配乐”，保留原“导入音乐”。目录来自桌面内置资源 ABI，显示名称、类别、作者、许可、来源、时长和循环许可；仅支持一次明确加入一个素材。没有自动匹配、分段淡入淡出或新的生成调用。加入后沿用现有四轨试听；本面板没有独立播放器，也不表示用户已听过。

## 保存与时长

- 先经原保存队列保存并读取 canonical 原始 record，以完整原始 JSON 的 hash 请求只读 `inspectBundledFilmAudioTarget`。显示的可用时长来自当前版本真实原片／无字幕副本的核验，不采用 `shot.seconds`，也不借全片混音的 fingerprint。
- 实际 target 未确认时不给可提交的默认时长。起点、时长、源偏移和增益须明确有效；仅资源本身允许循环时才可手动开启循环。加入时 native 再次独立核验工程、版本、资源和位置。
- 外部写入开始后，普通 autosave／flush 不可把旧 renderer 快照写回。正常返回采用真实保存 record，不为确认而额外覆盖写入。未知结果不重发 add；原工程全局待核对入口跨页面／作品保留，退出回执为 unknown／failed，默认留窗。
- 只读核对先用合法四字段 inspect：BUSY 或传输异常不证明旧写入结束；有效非 BUSY 结果才证明同 factory 先前 add 已结束，随后重新读取 canonical。禁止靠等待或连续相同旧 hash 判断完成。
- canonical 仅有本次唯一素材追加、目标和旧片段仍可保留时，精确合并至最新原稿并沿原工程 recovery lease 保存。切到另一作品时不 apply／写入该作品。无法证明安全合并则保留两份状态，展示差异类别、计数和可复制文字备忘；用户可明确选择“采用已保存版本并放弃这份未保存稿”。点击仍重新核验写入完成、fresh record 和原稿身份，陈旧选择不会执行。文字备忘不包含媒体或全部设置，不是工程备份。

## 撤销与范围

本次新增片段有独立“移除”按钮，仅删除当前工程这一个片段引用，素材文件保留；Ctrl+Z 保持已有字段历史，不冒充撤销素材添加。未确认写入期间不可重复添加或移除。原作品读不到时明确保留未确认状态与待核对入口，不声称已经删除或未改动，不自动覆盖写回。

## 保存生命周期补验

后续真实宿主发现并收窄修复三类出口：切到别的作品且原稿未新增编辑时，冲突审阅采用仍保留的请求基线；原工程未确认写入时，作品菜单／作品库重新打开优先展示保留稿，不能被旧 canonical 盖掉；添加／核对已经确定完成后，release 阶段保存新编辑失败单独说明，保留原 failed 保存队列与退出失败回执，不制造已失去 external lease 的假 unknown，也不重复 add。

定向回归增加无额外编辑的 foreign 冲突、add／recover 的确认后 release 保存失败及重试、真实菜单切走再切回的保留稿。原宿主夹具卸载后等待本夹具所有已进入的保存、lease／队列及原生文件写入 Promise，再删除临时目录；不靠 rm 重试、睡眠或忽略 ENOTEMPTY。

以上保存／历史／notice 联合 **7 文件 132 项通过**；这属于宿主交互与真实临时文件证据，不是浏览器像素或 Electron 全链路验收。
