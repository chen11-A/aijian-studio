# 上下文创作助手

## 目标与范围

在现有右侧助手中使用已选择的 ChatGPT 官方文本模型进行多轮文字对话。
上下文包含当前工作位置和明确预览的作品片段，不自动发送整部作品。
回复是创作建议，不代表项目已经修改、媒体已经生成或任务已经执行。
附件、语音、新供应商、自动图像/视频生成不在本轮范围内。

## 设计约束

- 复用官方账号、模型目录核验和主进程逐次发送确认，不新增认证方式。
- 项目、分集与账号隔离；退出或切换账号后不继承另一账号的会话。
- 会话正文只在当前运行的内存中保留；收起助手不应丢失会话。重启不恢复正文。
- 仅发送有界近期对话；较早消息被省略时明确告知，不偷偷调用模型生成摘要。
- 自动关联工作位置；作品片段可查看和取消。未保存状态与版本必须明确。
- 来源、作品和历史回复是数据，不是系统指令；不执行回复中的代码或工具调用。
- 作品变更通过既有审阅、版本检查和显式确认流程处理；不能从普通聊天绕过。
- UNKNOWN 不是失败重试许可。发送后结果不明时保留操作标识，禁止自动重发。
- IPC 验证来源窗口、数据形状、长度、范围与账号；凭据不进入前端、上下文或日志。

## 实施顺序

1. 固定凭据无关的对话与上下文契约，建立主进程验证、操作回执及纯文本返回通道。
2. 连接真实编辑器的上下文发布与助手会话，先展示发送预览，再调用原生确认。
3. 验证项目/账号切换、编辑期间失效、重复发送、拒绝授权和未知结果等边界。
4. 独立审查冻结候选，运行回归与构建；隔离界面观察与真实账号推理分别记录。

## 通道与上下文

`AssistantChatBridge` 提供 `preview`、`send`、`discardPreview`、`getOperation`
和 `listPending`。共享类型位于 `packages/contracts/src/assistant-chat.ts`，
从已有 `official-text` 类型入口导出；不改 Python HTTP DTO。

前端只传已保存对象的引用、版本、哈希和 revision。主进程读取真实项目、分集与
对象内容，冻结 `outboundText`、操作 ID 和输入哈希。预览不是生成，不调用模型。
原生确认后、供应商请求前再次检查版本及预览是否被撤销；变化时不发送。
创作库属于项目，版本的 `episode_id=null`；当前分集仍须属于同一项目。

首版引用覆盖剧本场次、分镜镜头、人物、场景与世界设定。编辑器发布实际显示的
对象 ID，缺失或无效的 ID 不回退到首项。未保存内容、读取失败和 fixture 内容
不生成可发送引用。每片最多 4000 字符，总片段最多 12000 字符；截断需提示。

主进程维护按账号、项目和分集隔离的内存会话。每次最多发送近期 12 条历史消息，
历史总量最多 24000 字符，当前消息最多 8000 字符；当前消息只加入一次。
预览明确显示历史省略数量与上下文截断状态。

新会话清空当前可见对话并更换会话标识，不清除未知操作记录。仅切换页面不重建
会话；切换账号、项目或分集则建立新的会话。发送后的回复若仍属于同一会话，
即使页面或选中内容已改变，也保留回复并提示它基于发送时的旧上下文。
离开后再返回相同账号、项目或分集，不能把旧异步结果插入新会话。

当前进程最多保留 64 个会话；达到上限时明确阻止新会话预览，不静默丢弃历史。
未使用的预览五分钟后失效，新预览替换本会话旧预览，撤销的预览及时释放。

发送前将操作身份、范围、哈希和 UNKNOWN 状态持久化并核对；失败时零供应商请求。
回执不含会话正文。`listPending` 不以页面或 session ID 为隔离条件，防止切页或
新会话绕过未知操作；重启后仍可查询。已完成但内存正文丢失时返回明确状态，
不能假称恢复了回复。清空对话不清除未知操作回执。

操作回读同时核对账号、项目和分集，不凭操作 ID 跨范围返回正文。内存会话绑定
认证代际，切换账号后旧会话标识不能用于重新取得或继续此前历史。
回执文件身份使用精确整数核对，避免 Windows 大文件编号被普通数字舍入。

## 项目结构与代码风格

- `packages/contracts/src`：新增 TypeScript 输入、结果和桥接类型。
- `apps/desktop/src`：IPC、主进程操作回执，复用现有官方文本 runtime。
- `apps/studio-web/src/aivora`：助手界面、会话状态及编辑器上下文。
- 测试与实现同目录，使用现有 Vitest；不增加依赖或数据库迁移。

沿用显式判别联合和默认拒绝方式，例如现有 `OfficialTextGeneration` 的
`NOT_SENT` 与 `REMOTE_UNKNOWN`，不能合并为可重试的普通错误。
界面输出用 React 文本节点，不使用模型输出构造 HTML。

## 验收

- 能输入、审阅并发送文字，显示真实通道返回或明确的未发送/未知状态。
- 追问携带本会话允许范围内的历史；切换作品、分集、账号后不会串用历史或内容。
- 当前对象的片段与版本可预览；取消携带后请求中不含该片段。
- 作品内容更新或作用域变化使旧预览失效，不能悄悄换成未经审阅的新内容。
- 拒绝原生确认不调用推理；未知发送不自动重试；快速重复点击只发送一次。
- 回执写入失败或回读不一致时零发送；重启、新会话和切页不能绕过未知回执。
- 原生确认等待期间切换选择、编辑变脏或 A→B→A 后旧预览不能发送。
- 收起再打开可继续本次会话；新会话行为和历史省略范围可见。
- 默认不修改作品，回复不能触发任意工具、文件、链接或外部调用。

## 交付边界

先完成本地与模拟测试，再单列真实账号推理证据。构建、截图和模拟成功不等于
真实推理或出片验收。现有依赖安全审计告警继续保留，不能据此批准正式发布。
不自动重启正在试用的产品，不自动推送；版本提交沿用集中治理入口。
