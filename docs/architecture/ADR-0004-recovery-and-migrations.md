# ADR-0004：恢复、迁移与回退语义

- 状态：Accepted for Phase 0
- 日期：2026-08-03

## 服务目标

- 已提交编辑和 ArtifactVersion：RPO=0。
- 未提交 UI 状态：最多损失一个 5 秒自动保存周期。
- 本地任务：应用重启后 60 秒内恢复为可解释状态。
- 远程任务：状态未知时不自动重提；RTO 取决于供应商查询或人工对账。
- 30 GB 参考项目：本地快照创建目标 ≤10 分钟，恢复并验证目标 ≤30 分钟；最终数字由 W4 基准修订。

## 决定

数据库、项目 manifest、Artifact Schema、WorkflowDefinition、Provider 协议和 Timeline 格式独立版本。破坏性迁移前停止领取新任务、等待安全检查点并创建只读验证快照。迁移使用 journal，可重复执行且可从步骤边界恢复。

应用二进制回退不等于项目降级。旧版本无法安全写新 Schema 时，只允许显示兼容错误或只读打开；只有恢复匹配快照才能恢复可写。媒体 CAS 以 temp 文件、hash verify、atomic rename 提交，数据库不会引用未完成 Blob。

## 必测矩阵

W8、W24、W36 和每个 RC 执行 N-2→N、迁移中断、磁盘满、快照损坏、应用回退、只读打开、远程付费任务仍在运行和 CAS 缺失/多余 Blob。任何已提交数据丢失、旧程序误写或远程未知自动重提均为发布阻断。
