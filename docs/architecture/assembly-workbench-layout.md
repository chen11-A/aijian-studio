`EpisodeMediaAssemblyPanel`将保存、相邻原件监看/裁剪及既有时间线前置。
装配概况、画布、素材加入、手工候选和准备状态保留在下方展开区，组件仍挂载。
原有脚本/字幕/审片/导出区保留，不改变原审批或执行路径。

紧凑/较大监看使用按作品、分集、assembly/voice作用域区分的内存视图偏好。
它不进入装配内容、版本、持久日志或localStorage。尺寸只改变CSS高度；
相同原件的播放器、object URL、裁剪form和时间码输入不因尺寸切换重新挂载。
短窗口较大监看占用更多画面高度，轨道视口相应减小且仍可滚动。

时间轴的帧、缩放、滚动、快捷键及受保护编辑回调使用原实现。右栏改变可用
宽度时，原ResizeObserver和anchor算法保留当前帧相对视口的位置，并在边界
处合法夹紧；宽度变化可能改变像素scrollLeft，不应声称其数值恒定。恢复到
原宽度且未触及边界时，可核对原偏移恢复。导航卸载时间线后的缩放/滚动恢复
没有在本批新增持久存储，不把模式/布局保持夸大成任意重启恢复。

专业右栏由实际`DemoApp`外壳提供显式收起/恢复按钮。折叠偏好按页面保存于
同一model内存状态；Inspector/AI选中tab及原组件状态不被清空。整个aside
隐藏，隐藏内容退出键盘焦点顺序；恢复时可恢复仍可见的原右栏焦点，避免滚动
主编辑区。模式切换沿用相同作品、分集和制作对象，不改变质量或数据权限。
专业pane限制旧AI浮动样式的叠层范围，并为Tab行和上下文控件留出独立槽，
使Inspector/AI双向真实鼠标点击可达；正文继续使用原有有界滚动。

布局按钮没有保存、原操作GET、生成、编码、发布或费用处理器。装配
UNKNOWN仍必须保留原UUID和完整journal，恢复仍是显式只读准确核对。
布局操作不能自动发出核对请求，不能以最新head猜测原写入已成功。

原件监看继续是已核验完整原素材的独立播放器，不应用序列裁剪、字幕、混音，
也不代表帧精确审片或实时合成。原32MiB内嵌原件上限、保存后DRAFT编码和
正式签发边界不变。该页已有的typed Assistant/Inspector对象绑定缺项仍开放，
本批只保留其真实空/未接状态与作用域，不新增绑定或虚构上下文。
