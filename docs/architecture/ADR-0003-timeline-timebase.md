# ADR-0003：时间线使用有理数时间与显式 Conform

- 状态：Accepted for Phase 0
- 日期：2026-08-03

## 决定

所有持久化/API 时间值使用约分有理数 `{num, den}`，不使用浮点秒。Sequence 固定帧率（支持 24000/1001、24、25、30000/1001 等）；每个源媒体保留自己的 timebase、PTS/DTS 和探测报告。编辑点落在 Sequence 帧边界，音频内部以 48 kHz 样本计数。

VFR 输入在进入可编辑素材前生成 CFR 代理和时间映射；最终导出回连原片时按映射取样。代理与原片由内容哈希和映射版本关联。转场占用两侧手柄，手柄不足时必须报错或由人选择缩短，不静默重复帧。

## 验证

Phase 0 固定测试 23.976/24/25/29.97 fps、VFR 手机素材、44.1/48 kHz、Unicode/长路径和损坏媒体。30 分钟时间线从代理切回原片导出后，首尾 A/V 漂移不超过一帧；关键 Clip 边界逐帧符合黄金清单。
