# 界面中文文案表

现有界面里生硬、带术语或说不清楚的句子，按「原文、建议、位置」列出来。这里只列表，不改代码；GPT 合入时照表替换。对应《给Claude的任务书》3J-U15。

- 对象：6efe12d 的界面文字。位置写成 `文件:行`，文件都在 `apps/studio-web/src/aivora/` 下，后面写这句出现在界面的哪里。
- 原文里的 `…` 是代码里拼进去的变量，比如人名、数字。替换时保留变量，只改字。
- 同一句出现在好几处的，几处都要改。
- 表里提到的「镜头名」都写成「第 2 场第 3 个镜头」这种格式。只写「镜头 3」时，各场都有镜头 3，看不出是哪一个。

## 用词约定

替换时按这几条统一，表里的建议也照这个写：

| 不用                         | 用                             | 为什么                               |
| ---------------------------- | ------------------------------ | ------------------------------------ |
| 模型、文本模型、模型列表     | AI，或者直接说哪件事做不了     | 用户不关心是哪个模型                 |
| 接口、请求、返回、格式       | 说结果：没拿到、没法用、没回答 | 是程序的说法                         |
| 提示词、提示词工程师         | 画面说明                       | 用户写的是画面，不是提示词           |
| 起始画面                     | 开头画面                       | 说的是这一镜的第一张图               |
| 版本 N、第N版/M              | 第 N 版、共 M 版               | 全站一个说法，数字两边空一格         |
| 当前版本                     | 正在用这一版                   | 和 TakePicker 一致                   |
| 单独配音、画面自带           | 另外配音、用视频里的声音       | 「单独」「自带」说不清是哪边的声音   |
| 已中断                       | 软件关掉时没做完               | 用户不知道是被谁中断的               |
| 离线编剧、离线拆镜           | 没登录，先用软件自己的规则写   | 「离线」听起来像出了故障             |
| 让路、一路、各路             | 变小、这一轨、所有声音         | 是混音的行话                         |
| 草稿成片、正式发行、不是实拍 | 试做版、发布、AI 做的          | 官腔                                 |
| 沙箱                         | 演示                           | 是开发的说法                         |
| 第 1 场（当场名用）          | 场名留空，列表显示「还没起名」 | 场号已经单独显示，场名再写一遍是重复 |
| 写入分镜、放入剧本           | 放进分镜、放进剧本             | 同一个动作只用一个动词               |
