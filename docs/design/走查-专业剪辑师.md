# 走查意见：专业剪辑师

这是按「专业剪辑师」的视角，对着 `docs/design/` 的第二版原型逐屏走一遍写下的意见，属于专家走查，不是真人测试。原型是静态画面，拖动、播放、按帧走这些手感没有走到。`docs/development/ui-engineering-standards.md` 要求剪辑界面由真实剪辑师完成修剪、替换、补拍和崩溃后继续导出来验收，这份意见不能代替。

## 这个人和这次的任务

- 剪短剧 5 年，每天用 Premiere、DaVinci、剪映专业版，按帧工作，熟悉平台的响度要求。
- 拿到 AI 生成的第 1 集（三场、65 个镜头、4 分 34 秒），要在一天内修到能交给客户：替换坏镜头、修声音、字幕和封面，导出。
- 最在意：精确到帧、改了能回退、批量处理、看得到真实数值。

## 走一遍

| 界面       | 做了什么                                                            | 看到和想到的                                                                                                                                     |
| ---------- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 任务中心   | 看 130 段视频的状态，处理第 2 场第 22 个镜头 A 版失败               | 不确定和失败分得清，「不确定不让重发」是对的。失败原因和改法放在一起很省事。每行后面有小字编号，能拿去搜。但不能多选，也不能调整排队顺序。       |
| 一选多审片 | 比较第 2 场第 17 个镜头的 A、B、C，三个一起播，1/2/3 选版本         | 和 DaVinci 的多机位对比思路一致，键盘选版本顺手。对比表把「穿过身体」这种坏画面单独列出来很实用。缺放大和叠加对比。                              |
| 声音面板   | 第 2 场默认只看到情绪和一个音量；点「细调」看四层和时间线           | 默认画面对客户演示很干净。细调里音效标出来自哪个动作节点，对齐打斗很省事；「素材库里没有」直接标红，不会糊弄。但只能整层调音量，看不到响度数值。 |
| 字幕样式   | 横竖屏同时预览，换一句长台词看换行                                  | 平台按钮遮挡区标得清楚。缺逐句改时间和手动断行。                                                                                                 |
| 封面和片头 | 选片名居中，背景用第 1 场第 1 个镜头的起始画面，打开「AI 生成」标识 | 横竖封面和片头一起出，省事。背景只能选起始画面，不能取视频里任意一帧。                                                                           |
| 导出前检查 | 6 处问题，逐条点「去修」                                            | 每条问题都有位置，时间线上有标记，这是剪映没有做好的地方。只剩「去修」和「直接导出」，界面清楚了，但三处要先处理的得一处一处去修。               |

## 问题清单

| 编号 | 严重 | 界面                         | 问题                                                                                                                                               | 建议                                                                                                                                                               |
| ---- | ---- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| P1   | 高   | 导出前检查、一选多、声音面板 | 小字里的时间只到秒（`2:38`），没有帧。「剪掉 0.4 秒黑屏」「剪到停住之前」都要按帧落点；UI 规范也要求剪辑界面显示帧准确的时间码。                   | 正文保持「第 2 场第 18 个镜头」；小字的时间在专业设置里切换成「时:分:秒:帧」，状态栏写作品帧率。剪辑页里的时间码一直按帧。                                         |
| P2   | 高   | 导出前检查                   | 去掉「一键修好」以后，三处要先处理的问题要进出剪辑三次。                                                                                           | 「去修」跳到剪辑后，剪辑页顶上那条提示里给「下一处」，按顺序走完这一批问题再回来；每处修改都进撤销历史，修过的地方在时间线上留标记。不在导出前检查里加回批量按钮。 |
| P3   | 高   | 声音面板、导出前检查         | 界面上不写分贝，也没有平均响度和峰值。交片前必须核对这两个数。                                                                                     | 界面保持 0 到 100；导出时另存一份检查报告（文本文件），里面写整片和每场的平均响度、最大峰值和目标值，数值和导出代码一致。报告在「打开文件夹」里能看到。            |
| P4   | 中   | 声音面板                     | 只能按层调音量，没有单个片段的音量、淡入淡出和关键帧，片段也不能拖动对齐；台词不能跨镜头做 J/L 剪。                                                | 细调的时间线里选中片段时，在右侧显示片段属性（音量、淡入、淡出、起点偏移），支持拖动和跨镜头的台词延续。                                                           |
| P5   | 中   | 声音面板                     | 一次只看一场，看不到场与场之间的衔接，比如第 1 场的不安配乐怎么进第 2 场。                                                                         | 加整集视图，场之间显示交叉淡化，可以从整集视图跳进单场。                                                                                                           |
| P6   | 中   | 一选多                       | 只能并排看，不能放大看手和道具，不能叠加擦除对比；C 要剪掉开头 0.4 秒，只能选完再去别处修。                                                        | 加放大和左右擦除对比；在版本上直接设入点、出点；显示每个版本用的描述有什么不同。                                                                                   |
| P7   | 中   | 任务中心                     | 不能多选批量处理，不能调整排队顺序（比如先做第 3 场给客户看），看不到请求编号，没法拿去问 Grok。                                                   | 列表支持多选后批量重试或移出；排队的可以「移到最前」；详情里加「复制请求编号」。                                                                                   |
| P8   | 中   | 字幕样式                     | 不能逐句改时间、手动断行、换字体；竖屏的平台遮挡区只有一种。                                                                                       | 加字幕列表（在自己的区域里滚动）逐句改时间和断行；遮挡区按平台给预设，例如抖音、快手、视频号竖屏和 B 站横屏。                                                      |
| P9   | 低   | 导出前检查                   | 导出设置只有作品本身的竖屏 1080×1920，没有帧率、码率、横竖两版一起导、只导字幕文件这些选项；保存位置在这一页也不能改。                             | 设置里给几个常用预设：发布用、给客户审片的小文件、留底的高画质；字幕文件可以单独导出。这一页只显示当前用的是哪个预设。                                             |
| P10  | 低   | 封面和片头                   | 背景只能选起始画面，片名字体不能换。                                                                                                               | 在一选多和剪辑里加「设为封面画面」，可以取任意一帧；给两三种片名字体。                                                                                             |
| P11  | 低   | 全局                         | 场记查出来的连贯问题（衣服、道具、站位、伤妆，例如第 3 场林晚该披着风衣、沈砚的纱布）在这 7 个界面里只以「接不上」的形式出现，没有集中查看的地方。 | 在分镜里加连贯检查面板，按场记角色的输出逐条跳转：它已经给出跳转的镜头和秒数，以及要改哪个字段。                                                                   |

## 要点

1. 大方向对：任务能恢复、不确定的不重发、导出前逐条检查并能跳到位置、四层声音分开、所有版本都保留。
2. 第二版主界面更干净：每屏一个主按钮，正文写「第几场第几个镜头」，编号和时间放进小字，声音默认只有情绪和音量。专业要的东西要放进小字、细调和导出报告，而不是放回主界面。
3. 最急的三件：小字时间码能切到帧；「去修」之后在剪辑里能按顺序走完一批问题，改动能撤销、留标记；导出时给一份写着真实响度数值的报告。
4. 声音和字幕现在只能整体调，交片前的细修还要回到别的软件；片段级的属性和逐句字幕是下一步。
5. 批量和排序决定一天能不能修完一集：任务多选、排队调整、版本上直接设入出点。
