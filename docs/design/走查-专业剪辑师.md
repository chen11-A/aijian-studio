# 走查意见：专业剪辑师

这是按「专业剪辑师」的视角，对着 `docs/design/` 的原型逐屏走一遍写下的意见，属于专家走查，不是真人测试。原型是静态画面，拖动、播放、按帧走这些手感没有走到。`docs/development/ui-engineering-standards.md` 要求剪辑界面由真实剪辑师完成修剪、替换、补拍和崩溃后继续导出来验收，这份意见不能代替。

## 这个人和这次的任务

- 剪短剧 5 年，每天用 Premiere、DaVinci、剪映专业版，按帧工作，熟悉平台的响度要求。
- 拿到 AI 生成的第 1 集，要在一天内修到能交给客户：替换坏镜头、修声音、字幕和封面，导出。
- 最在意：精确到帧、改了能回退、批量处理、看得到真实数值。

## 走一遍

| 界面       | 做了什么                                                  | 看到和想到的                                                                                                 |
| ---------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 任务中心   | 看 78 段视频的状态，处理 S04-07 版本 A 失败               | 不确定和失败分得清，「不确定不让重发」是对的。失败原因和改法放在一起很省事。但不能多选，也不能调整排队顺序。 |
| 一选多审片 | 比较 S04-07 的 A、B、C，三个一起播，1/2/3 选版本          | 和 DaVinci 的多机位对比思路一致，键盘选版本顺手。对比表把「伤在哪一侧」单独列出来很实用。缺放大和叠加对比。  |
| 声音面板   | 看第 4 场四层：对白、环境、音效、配乐                     | 音效标出来自哪个动作节点，对齐打斗很省事；「素材库里没有」直接标红，不会糊弄。但只能整层调音量。             |
| 字幕样式   | 横竖屏同时预览，换一句长台词看换行                        | 平台按钮遮挡区标得清楚。缺逐句改时间和手动断行。                                                             |

## 问题清单

| 编号 | 严重 | 界面                         | 问题                                                                                                                  | 建议                                                                                                                                                  |
| ---- | ---- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| P1   | 高   | 导出前检查、一选多、声音面板 | 时间码只到 0.1 秒，没有帧。「剪掉 0.4 秒黑屏」「剪到停住之前」都要按帧落点；UI 规范也要求剪辑界面显示帧准确的时间码。 | 时间码改成「时:分:秒:帧」，状态栏写作品帧率；默认给新手显示秒，专业设置里切换成帧。                                                                   |
| P2   | 高   | 导出前检查                   | 「剪掉黑的部分」「剪到停住之前」和「一键修好 3 处」直接改剪辑，看不到修改范围，批量修完也不知道改了哪里。             | 每个修复先在时间线上预览要剪掉的范围；一键修好前列出改动清单；修过的地方在剪辑里留标记，全部进撤销历史。                                              |
| P3   | 高   | 声音面板、导出前检查         | 不显示响度数值。对小白友好，但剪辑师交片前必须看整片平均响度和最大峰值。                                              | 在默认收起的「高级」里显示整片和本场的平均响度、最大峰值，目标和导出代码一致（-16 LUFS，峰值 -1.5 dBTP）；混音条加峰值表。主界面的文字仍然不写 LUFS。 |
| P4   | 中   | 声音面板                     | 只能按层调音量，没有单个片段的音量、淡入淡出和关键帧，片段也不能拖动对齐；对白不能跨镜头做 J/L 剪。                   | 选中片段时在右侧显示片段属性（音量、淡入、淡出、起点偏移），支持拖动和跨镜头的对白延续。                                                              |
| P5   | 中   | 声音面板                     | 一次只看一场，看不到场与场之间的衔接，比如第 3 场的悬疑配乐怎么进第 4 场。                                            | 加整集视图，场之间显示交叉淡化，可以从整集视图跳进单场。                                                                                              |
| P6   | 中   | 一选多                       | 只能并排看，不能放大看手和伤口，不能叠加擦除对比；C 要剪掉开头 0.4 秒，只能选完再去别处修。                           | 加放大和左右擦除对比；在版本上直接设入点、出点；显示每个版本用的描述有什么不同。                                                                      |
| P7   | 中   | 任务中心                     | 不能多选批量处理，不能调整排队顺序（比如先做第 6 场给客户看），看不到请求编号，没法拿去问 Grok。                      | 列表支持多选后批量重试或移出；排队的可以「移到最前」；详情里加「复制请求编号」。                                                                      |
| P8   | 中   | 字幕样式                     | 不能逐句改时间、手动断行、换字体；竖屏的平台遮挡区只有一种。                                                          | 加字幕列表（在自己的区域里滚动）逐句改时间和断行；遮挡区按平台给预设，例如抖音、快手、视频号竖屏和 B 站横屏。                                         |
| P9   | 低   | 导出前检查                   | 导出设置只有作品本身的竖屏 1080×1920，没有帧率、码率、横竖两版一起导、只导字幕文件这些选项。                          | 在高级里给几个常用预设：发布用、给客户审片的小文件、留底的高画质；字幕文件可以单独导出。                                                              |
| P10  | 低   | 封面和片头                   | 背景只能选起始画面，片名字体不能换。                                                                                  | 在一选多和剪辑里加「设为封面画面」，可以取任意一帧；给两三种片名字体。                                                                                |
| P11  | 低   | 全局                         | 场记查出来的连贯问题（服装、道具、站位、伤妆）在这 7 个界面里只以「接不上」的形式出现，没有集中查看的地方。           | 在分镜里加连贯检查面板，按场记角色的输出逐条跳转：它已经给出跳转的镜头和秒数，以及要改哪个字段。                                                      |

## 要点

1. 大方向对：任务能恢复、不确定的不重发、导出前逐条检查并能跳转、四层声音分开、所有版本都保留，这些都是现有剪辑软件里难做好的地方。
2. 最急的三件：帧精度时间码；自动修复要先预览、能撤销、留标记；在高级里给出真实的响度数值。
3. 声音和字幕现在只能整体调，交片前的细修还要回到别的软件；片段级的属性和逐句字幕是下一步。
4. 批量和排序决定一天能不能修完一集：任务多选、排队调整、版本上直接设入出点。
5. 专业信息放在默认收起的「高级」里，主界面保持简单中文，和新手走查的意见不冲突。
