# 走查意见：第一次用的小白

这是按「第一次用的人」的视角，对着 `docs/design/` 的第二版原型逐屏走一遍写下的意见，属于专家走查，不是真人测试。原型只有静态画面，所以等待时间、真实生成质量、浏览器登录这些体验没有走到。正式验收仍要按 `docs/development/ui-engineering-standards.md` 的要求，找真实用户完成同样的任务并记录。

## 这个人和这次的任务

- 平时刷短视频，会用微信，会把文件拖来拖去，没用过剪辑软件，也没用过 AI 生成视频。
- 有 Grok 会员，但不知道会员额度怎么算。
- 手里有一篇两千字左右的小说《雨夜旧书店》（txt），分成三场：雨夜旧书店、码头仓库、医院走廊。
- 任务：做出第一部能发出去的短片。不想研究参数。

没登录、拖入小说：点 3 次做出成片，第 4 次点播放，符合「5 次点击以内」。中途软件意外关闭过的话多 2 次（查一下、接着做）。用「选择文件」代替拖放时，系统选文件窗口还要点 2 次，没登录时正好 5 次，没有余量。

## 和第一版比

| 第一版的问题                                           | 第二版                                                                     |
| ------------------------------------------------------ | -------------------------------------------------------------------------- |
| 首页的「成片 / 草稿」和「画风」是负担                  | 首页只留画面方向。画风用默认预设，草稿放进作品设置。                       |
| 首页有一个「雨夜巷战」示例，和自己的小说混在一起       | 去掉了，首页只有自己的作品。                                               |
| 恢复横幅里两个按钮并排，不知道先点哪个                 | 每个状态只有一个蓝色按钮：先「查一下，再接着做」，查完「接着做 47 段」。   |
| 导出前检查的「一键修好」「不修了，直接导出」后果说不清 | 只剩「去修」和「直接导出」。直接导出下面写清还剩几处、会留在成片里。       |
| 声音面板的分贝数字看不懂                               | 默认只有配乐情绪和一个 0 到 100 的音量，四层音量收在「细调」里，没有分贝。 |
| 镜头编号 S04-07、时间 02:15.9 看不懂                   | 正文写「第 2 场第 17 个镜头」，编号和时间只是后面的小字。                  |

## 问题清单

| 编号 | 严重 | 界面           | 问题                                                                                                     | 建议                                                                                                                                                                                                  |
| ---- | ---- | -------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| N1   | 高   | 首页、任务中心 | 不知道要等多久。为了不放假数据，准备和生成都没有时间估计，第一次用的人容易以为卡住了，或者不敢离开电脑。 | 显示真实的「已经用了多久」和「做好几段、一共几段」；全部做完时发系统通知；首页保留一个「回到进度」的入口。不显示猜出来的剩余时间。                                                                    |
| N2   | 高   | 开始生成前     | 额度焦虑：130 段视频看不出多少，也不知道够不够。                                                         | 在弹窗里写「会员用量可以在 Grok 网站上看」并给链接（要先确认 Grok 有这个页面）；版本数旁边直接写换算，例如「选 1 个：视频 65 段」。第一次的默认版本数是否改成 1，需要产品确认（现在作品设置默认 2）。 |
| N3   | 中   | 首页           | 用「选择文件」时没有余量：没登录时正好 5 次。                                                            | 拖放区写得更醒目：「直接把文件拖进来就行」；选文件窗口记住上次的文件夹。                                                                                                                              |
| N4   | 中   | 导出前检查     | 「去修」会跳到剪辑里。第一次用的人到了剪辑页可能找不到回来的路，也不知道改完要不要再检查。               | 跳过去的剪辑页顶上放一条「改完回到导出前检查」；回来时这一条自动重新检查，界面上写一句「刚才那处已经修好」。                                                                                          |
| N5   | 中   | 任务中心       | 意外关闭后要点两次（查一下、接着做），第二次看起来像重复。                                               | 保持两次：第二次会用额度（重新做的那 1 段），要让用户看清再点。查完的横幅已经写了用 1 段额度，可以把这句放在按钮旁边。                                                                                |
| N6   | 中   | 一选多         | 「必须重做 / 建议重做 / 可用」看得懂，但不知道是不是每个镜头都要自己来选一遍。                           | 一键出片时先默认用推荐的版本并标出来，只把「必须重做」的镜头放进「要你看一下」。是否默认采用推荐版本需要产品确认（现在的原则是由用户决定）。                                                          |
| N7   | 低   | 声音面板       | 「细调」点开以后内容很多，看到时间线有点慌。                                                             | 细调默认收着，收起后记住；收起时状态栏一直写一句「要分开调台词、环境声、音效和配乐，点细调」。                                                                                                        |
| N8   | 低   | 封面和片头     | 「AI 生成」标识能不能关、关了会怎样，不清楚。                                                            | 保留「建议一直打开」；关掉时提示一句后果。最终能不能关由产品负责人按发布平台和相关规定确认。                                                                                                          |
| N9   | 低   | 全局           | 顶栏的剧本、角色与场景、分镜、剪辑在一键出片里用不到，误点进去以后不知道怎么回首页。                     | 作品菜单里加「回到首页」；首页的状态栏一直显示当前进度。                                                                                                                                              |

## 要点

1. 点击次数达标：拖入小说时，已登录 2 次、没登录 3 次就能做出成片；最坏情况（没登录、用选择文件）正好 5 次。
2. 第二版把「要选的」和「两个按钮不知道点哪个」都去掉了：首页只选画面方向，每一屏只有一个蓝色按钮，导出前检查只有「去修」和「直接导出」。
3. 第一次用的人最大的不安仍是「要等多久」和「额度够不够」。这两件都不能编数字，只能用真实进度、做完通知和 Grok 官方用量页来缓解。
4. 「去修」跳走以后怎么回来，是第二版新出现的问题，要在剪辑页里补一条回来的路。
5. 和专业剪辑师的分歧（帧精度时间码、响度数值、默认采用推荐版本）用「默认简单、细调和小字里给全」的方式处理，不分成两套界面。
