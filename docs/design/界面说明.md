# AIVORA 界面说明

这份说明对应 `docs/design/` 里的 7 个原型。每一节写清：这个界面做什么、从哪进来、每个按钮点了会怎样、什么时候不能点、空着、加载中、出错时显示什么，以及界面上的数字从哪来。原型只是界面设计，没有接到软件里。

原型里的人物、台词、镜头、时长和数量都按测试小说《雨夜旧书店》算出来（`packages/aivora-prompts/fixtures/test-novel.md` 和提示词示例）：6 场、39 个镜头、正片 3 分 28 秒、22 句对白。产品里这些都来自打开的作品和真实的任务记录，没有的就不显示，不用假数据填。画面位置放的是表示光线的色块，产品里换成真实生成的画面。

## 通用规则

### 外壳

所有界面共用同一个专业工作区外壳，沿用现有 `apps/studio-web/src/aivora/pro/pro.css` 的布局：上面 48 像素的顶栏，下面 24 像素的状态栏，中间是工作区。

| 位置     | 控件                         | 做什么                                                                               | 不能点时                                         |
| -------- | ---------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------ |
| 顶栏左   | 作品名 / 第几集              | 打开作品菜单：新建作品、打开别的作品或别的集、改名、删除。删除前写清删掉的是哪一集。 | 还没有作品时显示「还没有作品」，菜单里只剩新建。 |
| 顶栏左   | 撤销、重做                   | 撤销或重做对这部作品的上一步修改。                                                   | 没有可撤销、可重做的修改时变灰。                 |
| 顶栏中   | 剧本、角色与场景、分镜、剪辑 | 切到这个阶段。数字前面打勾表示这一步做过。                                           | 还没有作品时变灰，悬停提示「先放入小说才能用」。 |
| 顶栏右   | Grok 会员                    | 显示会员连接状态。没登录时点它开始登录，已登录时显示能用的功能。                     | 一直能点。                                       |
| 顶栏右   | 任务                         | 打开任务中心。有要处理的任务时右上角显示数量。                                       | 一直能点。                                       |
| 顶栏右   | 导出成片                     | 打开导出前检查。                                                                     | 还没有生成好的镜头时变灰，悬停提示原因。         |
| 顶栏右   | 账号                         | 打开账号菜单：退出登录、取消正在进行的登录。                                         | 一直能点。                                       |
| 状态栏左 | 提示                         | 刚刚发生了什么，一句话。                                                             | 不是按钮。                                       |
| 状态栏中 | 后台生成                     | 正在做什么、排队几段，点它打开任务中心。                                             | 一直能点。                                       |
| 状态栏右 | 作品保存在                   | 作品文件夹的名字。                                                                   | 不是按钮。                                       |

### 每个界面都遵守

- 一屏放下：登录、设置、表单、弹窗和右侧的详情栏不出现滚动条，1280×800 和 1920×1080 都能完整看到。只有长列表（任务、问题、音效、模板）和聊天记录在自己的区域里滚动，整页不滚动。
- 按钮分组放：一个区域只有一个主按钮（蓝色实心），次要按钮放在旁边或下面，很少用的放进菜单。按钮不挤成一排。
- 不能点的按钮变灰，并用一句短话说明原因（悬停提示或写在按钮旁边）。
- 用简单中文：写「画面停住」不写「静帧」，写「声音太冲」不写分贝峰值，写「整片音量调到听着一样大」不写 LUFS。分贝只出现在声音面板的音量滑块旁边。
- 会用会员额度的按钮，旁边写清用几张图或几段视频。软件看不到剩余额度，所以不显示剩余额度，也不估算花多少钱。
- 状态不只靠颜色：成功、失败、警告都同时有文字或图标。
- 键盘能操作所有按钮，焦点有清楚的蓝色描边；系统开启「减少动态效果」时，加载动画停止。

### 颜色和字号

颜色沿用 `pro.css`，只改两处，都是为了让文字在深色面板上满足 WCAG AA 的 4.5:1 对比度：

| 用途       | 现在的值  | 原型用的值 | 原因                                     |
| ---------- | --------- | ---------- | ---------------------------------------- |
| 次要文字   | `#6e7682` | `#858d99`  | 原来在面板底色上只有 3.9:1，改后 5.3:1   |
| 主按钮底色 | `#5b8cff` | `#3d6fd9`  | 白字在原来的蓝色上只有 3.2:1，改后 4.7:1 |

最小字号 12 像素，正文 13 像素，标题 15 到 22 像素。

### 怎么看原型

直接用浏览器打开 `docs/design/` 里的 HTML 文件，或者先打开 `index.html` 看目录。网址后面加 `?state=状态名` 切换状态，例如 `01-home.html?state=confirm`。每个状态的截图在 `screenshots/`。

## 1. 新手首页（`01-home.html`）

软件打开时，如果没有打开的作品，就显示这一页。第一次用的人在这里把小说变成一部片子。

布局：左边是主区域，从上到下是标题、放小说的地方、三个默认选项、一键出片和点击步骤；右边是 Grok 会员、最近的作品和示例。

### 按钮

| 按钮                        | 做什么                                                                                                                                       | 什么时候不能点                                 |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 把小说拖到这里（拖放区）    | 读入 txt、md、docx、epub。读完马上新建一部作品，作品名用文件名，显示章数、字数和开头两行。                                                   | —                                              |
| 选择文件                    | 打开系统的选择文件窗口。                                                                                                                     | —                                              |
| 粘贴文字                    | 打开一个粘贴框，粘贴后同样新建作品。                                                                                                         | —                                              |
| 换一个文件                  | 换成别的小说。已经开始写剧本的话，先问要不要保留现在的作品。                                                                                 | 正在准备时变灰。                               |
| 画面：竖屏 9:16 / 横屏 16:9 | 选这部片子的画面方向，默认竖屏。                                                                                                             | 开始生成以后不能改，提示「已经开始生成画面」。 |
| 画风                        | 选画风预设，默认「写实电影感」。                                                                                                             | 同上。                                         |
| 先做：成片 / 草稿           | 成片用正式视频模型；草稿更快，但不能带定妆照，人物的脸可能会变。                                                                             | 同上。                                         |
| 一键出片                    | 依次让编剧、美术、导演、表演指导、动作指导、声音设计写好剧本和分镜。这一步只用文字模型，不生成画面。写完弹出「开始生成前，先看看要做多少」。 | 没放小说时变灰，旁边写「先把小说拖进来」。     |
| 登录 Grok 并出片            | 没登录时，一键出片换成这个按钮：先打开浏览器登录，在 Grok 页面点同意后自动回来，接着做一键出片的事。                                         | —                                              |
| 停下                        | 做完当前这一步就停，已经写好的留着，下次点一键出片接着做。                                                                                   | 只在准备中出现。                               |
| 用 Grok 会员登录（右侧）    | 打开浏览器登录。                                                                                                                             | 已登录时不显示。                               |
| 打开示例                    | 打开软件自带的示例「雨夜巷战」，不用会员额度。                                                                                               | —                                              |

开始生成前的弹窗（`?state=confirm`）：

| 按钮                     | 做什么                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------- |
| 每个镜头做几个版本 1/2/3 | 默认 2 个版本（作品设置里的默认值）。改了以后，表里视频的段数和总时长马上跟着变。      |
| 做完后自动检查并导出     | 默认勾上。全部生成完，自动做导出前检查，能自动修的修好，导出到「视频 › AIVORA」。      |
| 先看看分镜               | 关掉弹窗，打开分镜，什么都不生成。                                                     |
| 先不生成                 | 关掉弹窗，什么都不生成，不用额度。剧本和分镜已经保存。                                 |
| 开始生成                 | 把定妆照、起始画面、视频和配音全部排进任务，开始用会员额度。进度在状态栏和任务中心里。 |

### 状态

| 状态       | 网址参数  | 显示什么                                                                                                                    |
| ---------- | --------- | --------------------------------------------------------------------------------------------------------------------------- |
| 还没放小说 | `empty`   | 大的拖放区。一键出片变灰。右侧 Grok 会员显示「还没登录」和登录按钮，最近的作品显示「还没有做好的作品」。                    |
| 放了没登录 | `login`   | 小说卡片显示文件名、章数、字数和开头。主按钮是「登录 Grok 并出片」，说明不用在软件里输密码。                                |
| 正常       | `normal`  | 小说已放入，已登录。主按钮是「一键出片」，下面的四步里第一步已经打勾。                                                      |
| 准备中     | `loading` | 七个步骤，做完的打勾，正在做的写清做到哪（例如「正在写第 3 个人物：周烈」），还没做的变灰。可以离开这一页，进度在任务中心。 |
| 开始生成前 | `confirm` | 弹窗写清要做多少：30 张图（定妆照、场景图、道具图）、39 张起始画面、78 段视频（约 6 分 56 秒）、22 句配音。                 |
| 做好了     | `done`    | 成片卡片：时长、画面尺寸、保存位置、包含的内容，以及导出前自动修了什么。主按钮「播放」。                                    |
| 读不出文件 | `error`   | 红色提示写清哪个文件、为什么读不出（现在还不能读 PDF），怎么办（另存为 txt 或 docx，或粘贴文字），拖放区还在。              |

### 数据从哪来

章数和字数在本机读文件时算出。弹窗里的数量在剧本和分镜写完以后按真实结果算：图的张数 = 美术要出的定妆照、场景图、道具图 + 每个镜头一张起始画面；视频段数 = 镜头数 × 每镜版本数；视频总时长 = 所有镜头时长之和 × 版本数；配音句数 = 剧本里的对白句数。原型里的数字来自测试小说的提示词示例。

### 做出第一部片子要点几次

「做出」指成片文件已经导出保存。拖文件不算点击。

| 情况                   | 要点的                                                             | 次数 |
| ---------------------- | ------------------------------------------------------------------ | ---- |
| 已登录，拖入小说       | 一键出片 → 开始生成                                                | 2    |
| 没登录，拖入小说       | 登录 Grok 并出片 → 浏览器里点同意 → 开始生成                       | 3    |
| 没登录，用「选择文件」 | 选择文件 → 双击文件 → 登录 Grok 并出片 → 浏览器里点同意 → 开始生成 | 5    |

做好以后点「播放」看片子，再加 1 次。生成中有镜头失败时，自动重试做完还不行，就停在任务中心等用户决定，这时会多出处理失败的点击。

## 2. 任务中心（`02-tasks.html`）

看所有生成任务的进度、处理失败的任务、软件意外关闭后接着做。从顶栏「任务」或状态栏「后台生成」进来。

布局：最上面是提醒横幅（有要处理的事时才出现），下面是这一批的总进度，再下面左边是筛选，中间是任务列表，右边是选中任务的详情。

### 按钮

| 按钮                                   | 做什么                                                                                                                              | 什么时候不能点               |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 查一下这 2 段                          | 用保存下来的请求编号去 Grok 查这两段的结果：做好了就下载存进作品；Grok 那边没有记录就标成「没发出去」。只查不重发，不会重复用额度。 | 正在查时变灰。               |
| 继续排队的 26 段                       | 继续还没发给 Grok 的任务。这些任务从来没发出去，继续不会重复用额度。                                                                | 已经在跑时换成「全部暂停」。 |
| 重新生成版本 B                         | 查完发现没发出去的版本，重新发一次，会用 1 段视频额度。                                                                             | —                            |
| 失败的全部重试（2）                    | 先弹窗写清要重试几段、会用几段额度，确认后重试。                                                                                    | 没有失败的任务时不显示。     |
| 左侧筛选                               | 按状态（全部、要你处理、正在生成、排队、做好了）或种类（视频、图片、配音）过滤列表，数字是真实条数。                                | —                            |
| 查一下 / 再试一次 / 重新生成（列表行） | 只对这一条做对应的事。                                                                                                              | —                            |
| 改描述再试（列表行）                   | 打开这一镜的描述，可以改完再试。                                                                                                    | —                            |
| 移出队列                               | 把排队的这一条拿掉，不会用额度，镜头保留原样。                                                                                      | 已经发出去的不能移出。       |
| 用这句描述再试（详情）                 | 用建议的描述重新生成这一版。建议来自动作指导写的安全提示和失败原因。                                                                | —                            |
| 自己改描述                             | 打开描述编辑，改完再试。                                                                                                            | —                            |
| 按原样再试                             | 描述不变，再发一次。                                                                                                                | —                            |
| 跳过这一版，用版本 B                   | 不再管这一版，这一镜先用另一个做好的版本。                                                                                          | 没有别的做好的版本时不显示。 |
| 重新读取 / 打开作品文件夹（出错时）    | 重新读任务记录；或者在资源管理器里打开作品文件夹。                                                                                  | —                            |
| 去分镜 / 回到首页（空的时候）          | 去生成第一个镜头，或者回到首页一键出片。                                                                                            | —                            |

### 任务的几种状态

| 界面上写的 | 意思                                                | 能做的                       | 不让做的                     |
| ---------- | --------------------------------------------------- | ---------------------------- | ---------------------------- |
| 排第 N     | 还没发给 Grok                                       | 移出队列                     | —                            |
| 正在生成   | 已经发出去，在等结果，显示已经等了多久              | 查看                         | 重复提交                     |
| 不确定     | 软件关闭时正在生成，不知道 Grok 有没有做完          | 查一下                       | 直接重新生成（会重复用额度） |
| 没发出去   | 查过了，Grok 那边没有这次的记录                     | 重新生成                     | —                            |
| 失败       | Grok 说做不了，或者等太久没有结果，自动重试也用完了 | 改描述再试、按原样再试、跳过 | 把失败的那一次改成成功       |
| 做好了     | 结果已经存进作品                                    | 去分镜里看                   | —                            |

自动重试最多 2 轮（作品设置里的默认值），用完以后才进「要你处理」。

### 状态

| 状态           | 网址参数    | 显示什么                                                                                                     |
| -------------- | ----------- | ------------------------------------------------------------------------------------------------------------ |
| 关闭后重新打开 | `normal`    | 黄色横幅：做好的 48 段都在，有 2 段不确定，先查一下再继续；排队已暂停，等用户确认。列表先列出要处理的 4 条。 |
| 查完了         | `recovered` | 绿色横幅：1 段已经做好并存进作品，1 段没发出去，可以重新生成。要处理的变成 3 条。                            |
| 空的           | `empty`     | 「现在没有任务」，说明任务从哪来，关掉软件也不会丢。                                                         |
| 加载中         | `loading`   | 列表和详情显示灰色占位条，写「正在读取任务记录…」。                                                          |
| 出错           | `error`     | 红色横幅：任务记录读不出来，做好的视频文件不受影响；给「重新读取」和「打开作品文件夹」。                     |

### 数据从哪来

总数和各状态的条数来自任务记录：视频 78 段 = 39 个镜头 × 每镜 2 个版本，图片 69 张 = 30 张定妆照、场景图和道具图 + 39 张起始画面，配音 22 句。「已经等了多久」是本机计时。失败原因原样转述 Grok 的返回，猜测的原因前面写「可能是」。

## 3. 导出前检查（`03-export-check.html`）

点「导出成片」时先进这一页。把会让成片出问题的地方都列出来，每一条都能一键跳到出问题的位置。

布局：左边是问题列表（按「要先处理」和「建议看看」分组），中间是出问题位置的画面、播放控制和整片时间线上的问题标记，右边是导出设置和导出按钮。

### 查哪些问题

| 界面上的名字 | 对应需求里的 | 怎么算（建议值，待确认）                             | 默认分组                     |
| ------------ | ------------ | ---------------------------------------------------- | ---------------------------- |
| 黑屏         | 黑屏         | 连续 0.2 秒以上几乎全黑                              | 要先处理                     |
| 画面停住     | 静帧         | 连续 0.8 秒以上画面完全不动                          | 建议看看                     |
| 没有声音     | 无声         | 某句对白没有配音，或者连续 2 秒以上什么声音都没有    | 建议看看                     |
| 缺字幕       | 缺字幕       | 打开了字幕，但某句对白没有字幕，或者字幕和剧本对不上 | 要先处理                     |
| 声音太冲     | 响度不合格   | 某一段峰值太高，手机外放会破音                       | 要先处理                     |
| 整片太小声   | 响度不合格   | 整片平均音量离目标太远                               | 导出时自动调好，只写一行说明 |

界面上不写 LUFS 和 dBTP。软件内部的目标值沿用现有导出代码（`services/api/src/aijian_api/story_film.py`：整体 -16 LUFS，峰值 -1.5 dBTP）。

### 按钮

| 按钮                                  | 做什么                                                                   | 什么时候不能点                                                  |
| ------------------------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------- |
| 重新检查 / 停止检查                   | 从头再查一遍；或者停在当前位置。                                         | —                                                               |
| 回到剪辑                              | 关掉这一页，回到剪辑。                                                   | —                                                               |
| 全部 / 要先处理                       | 过滤问题列表。                                                           | —                                                               |
| 跳到这里                              | 中间的画面和时间线跳到这个问题的开始位置，选中这一条。                   | —                                                               |
| 剪掉黑的部分                          | 把这个镜头开头或结尾黑的那段剪掉，镜头变短，后面的镜头往前挪。可以撤销。 | —                                                               |
| 自动调好                              | 把这一段太冲的声音压下来，其他地方不动。可以撤销。                       | —                                                               |
| 用对白补上                            | 用剧本里这句对白生成字幕，时间对齐配音。                                 | —                                                               |
| 剪到停住之前                          | 把镜头剪到画面停住的地方为止。                                           | —                                                               |
| 换一个版本                            | 打开这一镜的「一选多」。                                                 | 只有一个版本时变灰。                                            |
| 去配音                                | 打开这句对白的配音。                                                     | —                                                               |
| 加一段配乐 / 本来就要安静             | 给没声音的地方加配乐；或者标成没问题，以后不再提示。                     | —                                                               |
| 上一帧 / 播放这一段 / 下一帧          | 在问题位置附近看。                                                       | —                                                               |
| 在剪辑里打开这里                      | 回到剪辑，播放头停在这里。                                               | —                                                               |

### 数据从哪来

预览的句子和总句数来自剧本里的对白（22 句）。一行字数的默认值（竖屏 12、横屏 20）是建议值，待确认。

## 7. 「一选多」审片（`07-takes.html`）

同一个镜头生成了几个版本，并排对比，选一个用。从分镜的单镜工作台进来，导出前检查里的「换一个版本」也会进来。

布局：上面是镜头信息和上一镜、下一镜；中间几个版本并排，每个版本下面写看到的问题和「用这一版」；最下面是一起播放的控制；右边是逐项对比表、AI 审片的建议和再做几个版本。

### 按钮

| 按钮                     | 做什么                                                         | 什么时候不能点                   |
| ------------------------ | -------------------------------------------------------------- | -------------------------------- |
| 上一镜 / 下一镜          | 换到前后的镜头。                                               | 第一个、最后一个镜头时变灰。     |
| 用这一版（每个版本一个） | 这一镜改用这个版本，其他版本都留着，可以随时换回来。可以撤销。 | 版本还在生成或没做成时变灰。     |
| 三个一起播               | 所有版本同时从头播放，时间对齐。                               | —                                |
| 上一帧 / 下一帧          | 所有版本一起走一帧。                                           | —                                |
| 循环                     | 反复播这一镜。                                                 | —                                |
| 0.5× / 1×                | 慢放看动作。                                                   | —                                |
| 再做 2 个版本            | 用同样的描述再做 2 个版本，用 2 段视频额度。                   | —                                |
| 改描述再做               | 打开这一镜的描述，改完再做。                                   | —                                |

### 状态

| 状态       | 网址参数  | 显示什么                                                                                                  |
| ---------- | --------- | --------------------------------------------------------------------------------------------------------- |
| 正常       | `normal`  | 三个版本：A 必须重做（挡刀的是右臂）、B 可用并推荐、C 建议重做（开头 0.4 秒黑屏）。最后用哪一版由用户点。 |

### 数据从哪来

每个版本的问题和推荐来自两处：软件本地查出的黑屏和画面停住，以及审片角色看抽帧图写的结论（`packages/aivora-prompts/roles/review.json` 示例 2 的 S04-07）。审片只给建议、不打分；「用这一版」只有用户点了才生效。
