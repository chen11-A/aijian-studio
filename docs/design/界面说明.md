# AIVORA 界面说明

这份说明对应 `docs/design/` 里的 7 个原型。每一节写清：这个界面做什么、从哪进来、每个按钮点了会怎样、什么时候不能点、空着、加载中、出错时显示什么，以及界面上的数字从哪来。原型只是界面设计，没有接到软件里。

原型里的人物、台词、镜头、时长和数量都按测试小说《雨夜旧书店》算出来（`packages/aivora-prompts/fixtures/test-novel-2000.txt` 和提示词示例）：三场，分别是第一场 雨夜旧书店、第二场 码头仓库、第三场 医院走廊；65 个镜头，正片 4 分 31 秒，加 3 秒片头共 4 分 34 秒，33 句台词。产品里这些都来自打开的作品和真实的任务记录，没有的就不显示，不用假数据填。画面位置放的是表示光线的色块，产品里换成真实生成的画面。

## 通用规则

### 外壳

所有界面共用同一个专业工作区外壳，沿用现有 `apps/studio-web/src/aivora/pro/pro.css` 的布局：上面 48 像素的顶栏，下面 24 像素的状态栏，中间是工作区。

| 位置     | 控件                         | 做什么                                                                               | 不能点时                                         |
| -------- | ---------------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------ |
| 顶栏左   | 作品名 / 第几集              | 打开作品菜单：新建作品、打开别的作品或别的集、改名、删除。删除前写清删掉的是哪一集。 | 还没有作品时显示「还没有作品」，菜单里只剩新建。 |
| 顶栏左   | 撤销、重做                   | 撤销或重做对这部作品的上一步修改。                                                   | 没有可撤销、可重做的修改时变灰。                 |
| 顶栏中   | 剧本、角色与场景、分镜、剪辑 | 切到这个阶段。                                                                       | 还没有作品时变灰，悬停提示「先放入小说才能用」。 |
| 顶栏右   | Grok 会员                    | 显示会员连接状态。没登录时点它开始登录，已登录时显示能用的功能。                     | 一直能点。                                       |
| 顶栏右   | 任务                         | 打开任务中心。有要处理的任务时右上角显示数量。                                       | 一直能点。                                       |
| 顶栏右   | 导出成片                     | 打开导出前检查。是普通按钮，不抢页面自己的主按钮。                                   | 还没有生成好的镜头时变灰，悬停提示原因。         |
| 顶栏右   | 账号                         | 打开账号菜单：退出登录、取消正在进行的登录。                                         | 一直能点。                                       |
| 状态栏左 | 提示                         | 刚刚发生了什么，一句话。                                                             | 不是按钮。                                       |
| 状态栏中 | 后台生成                     | 正在做什么、排队几段，点它打开任务中心。                                             | 一直能点。                                       |
| 状态栏右 | 作品保存在                   | 作品文件夹的名字。                                                                   | 不是按钮。                                       |

### 每个界面都遵守

- 一屏放下：登录、设置、表单、弹窗和右侧的详情栏不出现滚动条，1280×800 和 1920×1080 都能完整看到。只有长列表（任务、问题、音效、模板）和聊天记录在自己的区域里滚动，整页不滚动。
- 一次只突出一个按钮：每一屏、每一种状态里最多一个主按钮（蓝色实心），就是这时最该点的那一个。顶栏的「导出成片」也是普通按钮。次要按钮放在旁边或下面，很少用的放进菜单。按钮不挤成一排。
- 不能点的按钮变灰，并用一句短话说明原因（悬停提示或写在按钮旁边）。
- 用简单中文：写「画面停住」不写「静帧」，写「声音太冲」不写峰值，写「整片音量调到听着一样大」不写响度单位。界面上不写分贝，音量都用 0 到 100。
- 镜头在正文里写成「第 2 场第 17 个镜头」。内部编号（`scene-2-shot-17`）和时间（`2:34`）只做跟在后面的小字，给要查找、要对时间的人看。
- 会用会员额度的按钮，旁边写清用几张图或几段视频。软件看不到剩余额度，所以不显示剩余额度，也不估算花多少钱。
- 状态不只靠颜色：成功、失败、警告都同时有文字或图标。
- 键盘能操作所有按钮，焦点有清楚的蓝色描边；系统开启「减少动态效果」时，加载动画停止。

### 颜色和字号

颜色沿用 `pro.css`，只改两处，都是为了让文字在深色面板上满足 WCAG AA 的 4.5:1 对比度：

| 用途       | 现在的值  | 原型用的值 | 原因                                     |
| ---------- | --------- | ---------- | ---------------------------------------- |
| 次要文字   | `#6e7682` | `#858d99`  | 原来在面板底色上只有 3.9:1，改后 5.3:1   |
| 主按钮底色 | `#5b8cff` | `#3d6fd9`  | 白字在原来的蓝色上只有 3.2:1，改后 4.7:1 |

最小字号 12 像素（编号小字也是 12 像素，用次要文字的颜色和等宽字体），正文 13 像素，标题 15 到 22 像素。

### 怎么看原型

直接用浏览器打开 `docs/design/` 里的 HTML 文件，或者先打开 `index.html` 看目录。网址后面加 `?state=状态名` 切换状态，例如 `01-home.html?state=confirm`。每个状态的截图在 `screenshots/`。

## 1. 新手首页（`01-home.html`）

软件打开时，如果没有打开的作品，就显示这一页。第一次用的人在这里把小说变成一部片子。

布局：左边是主区域，从上到下是标题、放小说的地方、画面方向、一键出片和点击步骤；右边是 Grok 会员和最近的作品。

首页只留一个选项「画面方向」。画风不在首页选：美术按默认预设「写实电影感」定画风，之后在「角色与场景」里可以改。成片还是草稿也不在首页选：一键出片默认出成片，草稿放在作品设置里。软件自带的示例不放在首页。

### 按钮

| 按钮                         | 做什么                                                                                                                                       | 什么时候不能点                                 |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| 把小说拖到这里（拖放区）     | 读入 txt、md、docx、epub。读完马上新建一部作品，作品名用文件名，显示场数、字数和开头两行。                                                   | —                                              |
| 选择文件                     | 打开系统的选择文件窗口。                                                                                                                     | —                                              |
| 粘贴文字                     | 打开一个粘贴框，粘贴后同样新建作品。                                                                                                         | —                                              |
| 换一个文件                   | 换成别的小说。已经开始写剧本的话，先问要不要保留现在的作品。                                                                                 | 正在准备时变灰。                               |
| 画面：竖屏 9:16 / 横屏 16:9  | 选这部片子的画面方向，默认竖屏。                                                                                                             | 开始生成以后不能改，提示「已经开始生成画面」。 |
| 一键出片                     | 依次让编剧、美术、导演、表演指导、动作指导、声音设计写好剧本和分镜。这一步只用文字模型，不生成画面。写完弹出「开始生成前，先看看要做多少」。 | 没放小说时变灰，旁边写「先把小说拖进来」。     |
| 登录 Grok 并出片             | 没登录时，一键出片换成这个按钮：先打开浏览器登录，在 Grok 页面点同意后自动回来，接着做一键出片的事。                                         | —                                              |
| 停下                         | 做完当前这一步就停，已经写好的留着，下次点一键出片接着做。                                                                                   | 只在准备中出现。                               |
| 用 Grok 会员登录（右侧）     | 打开浏览器登录。                                                                                                                             | 已登录时不显示。                               |
| 播放、打开文件夹、去剪辑里改 | 做好以后：播放成片；在资源管理器里打开成片所在的文件夹；去剪辑接着改。                                                                       | 只在做好了以后出现。                           |

开始生成前的弹窗（`?state=confirm`）：

| 按钮                     | 做什么                                                                                 |
| ------------------------ | -------------------------------------------------------------------------------------- |
| 每个镜头做几个版本 1/2/3 | 默认 2 个版本（作品设置里的默认值）。改了以后，表里视频的段数和总时长马上跟着变。      |
| 做完后自动检查并导出     | 默认勾上。全部生成完，自动做导出前检查，能自动修的修好，导出到「视频 › AIVORA」。      |
| 先看看分镜               | 关掉弹窗，打开分镜，什么都不生成。                                                     |
| 先不生成                 | 关掉弹窗，什么都不生成，不用额度。剧本和分镜已经保存。                                 |
| 开始生成                 | 把定妆照、起始画面、视频和配音全部排进任务，开始用会员额度。进度在状态栏和任务中心里。 |

### 状态

| 状态       | 网址参数  | 显示什么                                                                                                                    |
| ---------- | --------- | --------------------------------------------------------------------------------------------------------------------------- |
| 还没放小说 | `empty`   | 大的拖放区。一键出片变灰。右侧 Grok 会员显示「还没登录」和登录按钮，最近的作品显示「还没有做好的作品」。                    |
| 放了没登录 | `login`   | 小说卡片显示文件名、场数、字数和开头。主按钮是「登录 Grok 并出片」，说明不用在软件里输密码。                                |
| 正常       | `normal`  | 小说已放入，已登录。主按钮是「一键出片」，下面的四步里第一步已经打勾。                                                      |
| 准备中     | `loading` | 七个步骤，做完的打勾，正在做的写清做到哪（例如「正在写第 3 个人物：周烈」），还没做的变灰。可以离开这一页，进度在任务中心。 |
| 开始生成前 | `confirm` | 弹窗写清要做多少：30 张图（定妆照、场景图、道具图）、65 张起始画面、130 段视频（约 9 分 2 秒）、33 句配音。                 |
| 做好了     | `done`    | 成片卡片：时长、画面尺寸、保存位置、包含的内容，以及导出前自动修了什么。主按钮「播放」。                                    |
| 读不出文件 | `error`   | 红色提示写清哪个文件、为什么读不出（现在还不能读 PDF），怎么办（另存为 txt 或 docx，或粘贴文字），拖放区还在。              |

### 数据从哪来

场数和字数在本机读文件时算出（测试小说 3 场、1,979 字，不算空格和换行）。弹窗里的数量在剧本和分镜写完以后按真实结果算：图的张数 = 美术要出的定妆照、场景图、道具图（6 个人物 21 张、4 个地点、5 件道具，共 30 张）+ 每个镜头一张起始画面；视频段数 = 镜头数 × 每镜版本数；视频总时长 = 所有镜头时长之和 × 版本数（271 秒 × 2）；配音句数 = 剧本里的台词句数。

### 做出第一部片子要点几次

「做出」指成片文件已经导出保存。拖文件不算点击。

| 情况                   | 要点的                                                             | 次数 |
| ---------------------- | ------------------------------------------------------------------ | ---- |
| 已登录，拖入小说       | 一键出片 → 开始生成                                                | 2    |
| 没登录，拖入小说       | 登录 Grok 并出片 → 浏览器里点同意 → 开始生成                       | 3    |
| 没登录，用「选择文件」 | 选择文件 → 双击文件 → 登录 Grok 并出片 → 浏览器里点同意 → 开始生成 | 5    |

做好以后点「播放」看片子，再加 1 次。生成中软件意外关闭过，重新打开时在任务中心点一次「查一下，再接着做」。有镜头失败时，自动重试做完还不行，就停在任务中心等用户决定，这时会多出处理失败的点击。

## 2. 任务中心（`02-tasks.html`）

看所有生成任务的进度、处理失败的任务、软件意外关闭后接着做。从顶栏「任务」或状态栏「后台生成」进来。

布局：最上面是提醒横幅（有要处理的事时才出现），下面是这一批的总进度，再下面左边是筛选，中间是任务列表，右边是选中任务的详情。

每种状态只有一个蓝色按钮：关闭后重新打开时是「查一下，再接着做」，查完是「接着做 47 段」，读不出记录时是「重新读取」，没有任务时是「去分镜」。列表行和详情里的按钮都是普通按钮。

### 按钮

| 按钮                                | 做什么                                                                                                                                                                                       | 什么时候不能点               |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 查一下，再接着做                    | 先用保存下来的请求编号去 Grok 查关闭时正在生成的 2 段：做好了就下载存进作品，Grok 那边没有记录就标成「重新排队」。只查不重发，不会重复用额度。查完停下，告诉你查到了什么，再点一次才接着做。 | 正在查时变灰，写「正在查」。 |
| 接着做 47 段                        | 查完以后出现：把没发出去的 1 段和原来排队的 46 段接着发给 Grok。这些都从来没发出去，不会重复用额度；没发出去的那 1 段会用 1 段视频额度。                                                     | 已经在跑时换成「全部暂停」。 |
| 失败的全部重试（2）                 | 先弹窗写清要重试几段、会用几段额度，确认后重试。                                                                                                                                             | 没有失败的任务时不显示。     |
| 左侧筛选                            | 按状态（全部、要你处理、正在生成、排队、做好了）或种类（视频、图片、配音）过滤列表，数字是真实条数。                                                                                         | —                            |
| 查一下 / 再试一次（列表行）         | 只对这一条做对应的事。                                                                                                                                                                       | —                            |
| 改描述再试（列表行）                | 选中这一条，在右边详情里改描述再试。                                                                                                                                                         | —                            |
| 移出队列                            | 把排队的这一条拿掉，不会用额度，镜头保留原样。                                                                                                                                               | 已经发出去的不能移出。       |
| 用这句描述再试（详情）              | 用建议的描述重新生成这一版。建议来自动作指导写的安全提示和失败原因。                                                                                                                         | —                            |
| 自己改描述                          | 打开描述编辑，改完再试。                                                                                                                                                                     | —                            |
| 按原样再试                          | 描述不变，再发一次。                                                                                                                                                                         | —                            |
| 跳过这一版，用 B 版                 | 不再管这一版，这一镜先用另一个做好的版本。                                                                                                                                                   | 没有别的做好的版本时不显示。 |
| 重新读取 / 打开作品文件夹（出错时） | 重新读任务记录；或者在资源管理器里打开作品文件夹。                                                                                                                                           | —                            |
| 去分镜 / 回到首页（空的时候）       | 去生成第一个镜头，或者回到首页一键出片。                                                                                                                                                     | —                            |

### 任务的几种状态

| 界面上写的 | 意思                                                | 能做的                       | 不让做的                     |
| ---------- | --------------------------------------------------- | ---------------------------- | ---------------------------- |
| 排第 N     | 还没发给 Grok                                       | 移出队列                     | —                            |
| 正在生成   | 已经发出去，在等结果，显示已经等了多久              | 查看                         | 重复提交                     |
| 不确定     | 软件关闭时正在生成，不知道 Grok 有没有做完          | 查一下                       | 直接重新生成（会重复用额度） |
| 重新排队   | 查过了，Grok 那边没有这次的记录，接着做时重新发     | 移出队列                     | —                            |
| 失败       | Grok 说做不了，或者等太久没有结果，自动重试也用完了 | 改描述再试、按原样再试、跳过 | 把失败的那一次改成成功       |
| 做好了     | 结果已经存进作品                                    | 去分镜里看                   | —                            |

自动重试最多 2 轮（作品设置里的默认值），用完以后才进「要你处理」。

### 状态

| 状态           | 网址参数    | 显示什么                                                                                                                |
| -------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------- |
| 关闭后重新打开 | `normal`    | 黄色横幅：做好的 80 段都在，有 2 段不确定，先查一下再接着做；排队已暂停。列表先列出要处理的 4 条。                      |
| 查完了         | `recovered` | 绿色横幅：第 2 场第 23 个镜头的 A 版已经做好，B 版没发出去，会重新排进队里。要处理的变成 3 条。主按钮「接着做 47 段」。 |
| 空的           | `empty`     | 「现在没有任务」，说明任务从哪来，关掉软件也不会丢。                                                                    |
| 加载中         | `loading`   | 列表和详情显示灰色占位条，写「正在读取任务记录…」。                                                                     |
| 出错           | `error`     | 红色横幅：任务记录读不出来，做好的视频文件不受影响；给「重新读取」和「打开作品文件夹」。                                |

### 数据从哪来

总数和各状态的条数来自任务记录：视频 130 段 = 65 个镜头 × 每镜 2 个版本，图片 95 张 = 30 张定妆照、场景图和道具图 + 65 张起始画面，配音 33 句，一共 258 条。原型里做好的 80 段是第 1 场全部 38 段、第 2 场第 1 到 20 个镜头的 40 段，加第 21、22 个镜头的 B 版；排队的 46 段从第 2 场第 24 个镜头排到第 3 场最后。「已经等了多久」是本机计时。失败原因原样转述 Grok 的返回，猜测的原因前面写「可能是」。

## 3. 导出前检查（`03-export-check.html`）

点「导出成片」时先进这一页。把会让成片出问题的地方都列出来。这一页只有两种按钮：每条问题一个「去修」，右下角一个「直接导出」。

布局：左边是问题列表（按「要先处理」和「建议看看」分组），中间是选中的问题所在的画面和整片时间线上的问题标记，右边是导出设置和「直接导出」。

### 查哪些问题

| 界面上的名字 | 对应需求里的 | 怎么算（建议值，待确认）                             | 默认分组                     |
| ------------ | ------------ | ---------------------------------------------------- | ---------------------------- |
| 黑屏         | 黑屏         | 连续 0.2 秒以上几乎全黑                              | 要先处理                     |
| 画面停住     | 静帧         | 连续 0.8 秒以上画面完全不动                          | 建议看看                     |
| 没有声音     | 无声         | 某句台词没有配音，或者连续 2 秒以上什么声音都没有    | 建议看看                     |
| 缺字幕       | 缺字幕       | 打开了字幕，但某句台词没有字幕，或者字幕和剧本对不上 | 要先处理                     |
| 声音太冲     | 响度不合格   | 某一段峰值太高，手机外放会破音                       | 要先处理                     |
| 整片太小声   | 响度不合格   | 整片平均音量离目标太远                               | 导出时自动调好，只写一行说明 |

界面上不写响度单位。软件内部的目标值沿用现有导出代码（`services/api/src/aijian_api/story_film.py` 里整体响度和峰值的目标）。

### 按钮

| 按钮     | 做什么                                                                                                                                                                                                                                                                                                   | 什么时候不能点                     |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 去修     | 跳到剪辑里出问题的那个镜头、那一秒，并把这条问题建议的改法摆在那里，改不改由你：黑屏是剪掉黑的那段，声音太冲是把这一下调小，缺字幕是用剧本里的台词补上，画面停住是剪到停住之前或者换一个版本，没有声音是导入一个声音或加配乐，找不到文件是找回文件或改用别的版本。改完回到这一页时，这一条自动重新检查。 | —                                  |
| 直接导出 | 不管还剩什么问题，按右边的设置写出成片。还有问题时，按钮下面写清还剩几处、会怎样（例如「这些问题会留在成片里」「会跳过这两个镜头，成片少 25 秒」）。                                                                                                                                                     | 检查中变灰，写「检查完才能导出」。 |

不是按钮的地方：点问题列表里的一行，只是选中它，中间显示那个位置的画面，时间线上那个标记加白边；文件名可以直接改；字幕的两个勾直接勾。保存位置和「AI 生成」标识这里只显示，要改去设置和封面页。

### 状态

| 状态   | 网址参数   | 显示什么                                                                                           |
| ------ | ---------- | -------------------------------------------------------------------------------------------------- |
| 有问题 | `normal`   | 6 处问题，3 处要先处理。选中的一条在画面上用黄条写出问题，时间线上红黄标记标出全部位置。           |
| 检查中 | `checking` | 五项检查逐项打勾，写「第 37 个镜头，共 65 个」。「直接导出」变灰。                                 |
| 没问题 | `clean`    | 绿色对勾「没有发现问题」，「直接导出」可以点。                                                     |
| 出错   | `error`    | 2 个视频文件找不到，列出是哪个镜头的哪个版本，每条一个「去修」；其余 63 个镜头已经查过，没有问题。 |

### 数据从哪来

问题来自本机对导出用的版本做的检测。小字里的时间是成片里的位置（含 3 秒片头），按秒四舍五入，例如第 2 场第 18 个镜头的画面停住在 3 + 83 + 70 + 1.9 = 157.9 秒，写成 `2:38`。原型里的 6 处问题和声音设计、审片的提示词示例对得上：第 1 场第 19 个镜头缺的刹车声就是声音设计示例 1 写进 missing 的那一条。
