# 作品打包备份

输入本地作品文件夹，`packProject` 输出 `.aivora` ZIP 文件及清单；`importProject` 校验后输出实际导入文件夹路径。整个过程离线，适用于 Node 20+，支持中文和空格路径、Windows 与 Linux。

```ts
import { packProject, importProject } from './index.js';
await packProject('/作品/第一集', '/备份/第一集.aivora');
const folder = await importProject('/备份/第一集.aivora', '/恢复');
console.log(folder); // 已有同名作品时自动使用 第一集 (1)
```

Windows 路径由调用者使用 `path.join` 构造，或使用正确转义的字符串。输出备份不得放在原作品文件夹中，也不会覆盖已有备份。

清单保留相对路径、文件长度和 SHA-256 校验值，空目录也保留。文件内容逐字节恢复；修改时间、权限和硬链接关系不作保留。目录名采用跨平台安全规则，拒绝 Windows 保留名称、尾空格、尾句点、反斜杠、绝对路径、`..`、重复及大小写碰撞路径。拒绝符号链接和加密、多卷、ZIP64 备份；导入只接受本模块格式与版本的清单。

可选第三参数 `{ maxBytes, maxFiles }`，默认最大解压内容 512 MiB、10000 个文件。解压前检查中央目录的数量和展开大小，随后核实全部文件校验值再创建目标作品。同名目标原子地创建新目录，写入失败清除新建的不完整目录。文件层级冲突也会报中文错误。内部同步 ZIP 操作会占用内存；大作品应在工作线程中调用，且本模块不是面向不可信超大文件的流式备份方案。清单校验用于检测损坏，不提供来源签名或防篡改认证。

在上级目录运行 `npx vitest run project-archive`。测试覆盖往返一致、中文路径、空目录、同名改名、损坏、路径跳出、文件数与大小限制及失败清理。
