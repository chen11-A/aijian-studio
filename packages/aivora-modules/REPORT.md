## P0 峰值

基线129条实测62条采样峰值超过0dBFS，最高 **+15.332722dBFS**；80条超过-1阈值的素材重新处理。采用固定衰减后Vorbis重编码，再实际解码测真峰值与采样峰值；如编码后仍超标则继续衰减重测。保留瞬态，不为强行达到 -18 LUFS 破坏动态。较低响度明确标记 peakLimited 并记录实际值；极短<400ms无法实测积分响度可记录null及中文说明，但峰值不能豁免。

check.py 现检查 `loudnorm.input_tp <= -1`、浮点解码采样峰值 <= -1dBFS，验证作者和真实测量与清单一致。逐条历史修复在 [PEAK_REPAIR.json](../../assets/audio-library/PEAK_REPAIR.json)，最终136条最大真峰值 **-1.05 dBTP**、最大采样峰值 **-1.052554 dBFS**，两类超标均0。普通检查实际退出0、问题为空；严格需求仍有18项未达标。原样普通输出见 [CHECK_OUTPUT.json](../../assets/audio-library/CHECK_OUTPUT.json)，严格输出见 [STRICT_CHECK_OUTPUT.json](../../assets/audio-library/STRICT_CHECK_OUTPUT.json)。完整验收记录在 [VALIDATION.json](../../assets/audio-library/VALIDATION.json)。

## 模块修复

- audio-picker：中文同义词、动作与地面选择；场景设备自动安排；segments循环/交叉淡化接曲铺满；排除上一场同源派生曲；找不到真实素材时返回中文警告。它输出调度计划，调用方必须执行segments与淡入淡出。
- export-check：includeOriginalAudio默认true，把视频原声纳入无声检查；显式同文件声音片段替代默认原声；黑屏区间从静帧报告中剔除。
- loudness：视频转WAV/OGG等纯音频时仅映射音轨；无音轨、格式和输出冲突有具体中文错误。
- project-archive：yazl/yauzl流式ZIP64，逐文件SHA-256；MP4/PNG/OGG STORE，默认20GiB；路径、符号链接、大小、清单和损坏检查保留。
- subtitles：默认fontsdir从模块位置定位仓库Noto；真实测试禁用系统字体仍能烧录；中文避头尾标点，超长英文数字按字符拆分。
