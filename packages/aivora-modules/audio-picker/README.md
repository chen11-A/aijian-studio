# 配乐和音效挑选器

`pickAudio(scene, library)` 输入本地清单、情绪、场景描述、时长与镜头/动作节点，返回配乐计划、台词压低区间、环境音、动作音效和中文缺项警告。纯规则与中文同义词，不联网、不调用模型。

```ts
import { pickAudio } from './index.js';
const plan = pickAudio({
  emotions: ['温暖'], description: '温暖场景', duration: 130,
  shots: [{ duration: 130, hasDialogue: false, actions: [] }],
}, library);
console.log(plan.music?.segments, plan.warnings);
```

时间单位为秒。配乐时间相对整场，镜头音效相对镜头。`segments` 是必须执行的播放计划：包含素材、入点、起止、淡入淡出。渲染方需叠加重叠片段的音量包络，再应用 `gainDb`、配乐总淡入淡出和 `ducking`。不能只播放顶层 `assetId` 一次而忽略 segments。

已验证可循环素材连续重复铺满，无间隙；短非循环素材使用最长半秒交叉淡化。同情绪配乐可接第二首，没有第二首也生成交叉淡化重复计划，不因素材短而直接无配乐。非循环曲的自动交叉淡化仍需试听，不等同已认证的音乐乐句循环。上一场配乐通过 `previousMusicId` 排除，连同同一原始来源的派生循环版一并排除。安静情绪仍可留白。

`synonyms.ts` 记录钢管/铁棍/拳头/匕首/倒地/医院等同义词。动作节点优先具体标签，钢管击打优先选择清单中的金属管受击拟音，不再优先使用金属罐；钢管、铁棍、棍子缺少精确管声标签时只返回缺素材警告，禁止退到一般金属击打或金属罐。钢管拖地只匹配拖拽，不会选金属击打，刀划伤不选厨刀刮擦。雨天地面优先湿脚步，医院/走廊/街道使用硬地面，缺硬地面不会使用草地。场景中的手机震动和心电监护仪可在没有动作节点时安排；明确指定过的同类动作不再重复添加。普通医院默认选择规律监护滴声；只有停搏、死亡或长鸣描述才选持续长鸣，心率加快时选加速滴声；动作节点的具体状态优先于场景状态。

同义词只用于寻找正确素材，不创造不存在的素材。没有医院底噪、真实雨声、人体倒地时返回 `warnings`；不会将设备声、音乐采样或软物落地改名冒充。小巷、巷子和夜街归入街道环境，优先使用已验证的真实街道循环。部分素材是明确标注的拟音，仍须根据画面判断材质与动作是否相符。新增金属管录音用于钢管受击和拖地场景拟音，原录音的具体金属材质未确认；标签用于剪辑意图匹配，不证明录制物体一定是钢管。

四个指定场景的真实输入和输出在 `SCENARIO_RESULTS.json`，可用 `scenarios.ts` 的 `runScenarios(library)` 复现。真实素材回归测试同时检查“能选对的内容”和“缺素材时不误选”；测试通过不代表四场景的素材要求都完成。目前真实雨声与130秒温暖配乐完整铺满，医院已选择规律监护滴声和硬地面脚步；小巷打斗已选择真实夜街循环和金属管击打拟音；人体倒地及医院走廊底噪仍会明确告缺，金属管具体材质仍需人工判断。

## 跨镜头连续环境音

优先渲染顶层 `plan.ambience`：其 `time/end/segments` 均使用整场时间，每个连续环境轨道只渲染一次。相邻镜头使用同一素材时合并；更换环境或出现无环境素材的镜头时才结束轨道。`gainAutomation` 使用整场时间，给出每段的**最终增益**（有台词 -12 dB，其他 -6 dB），覆盖轨道 `gainDb`，不要重复相加。循环边界在素材实际结束时发生，与切镜头时间无关。

`plan.shots[i].ambience` 是同一轨道的镜头裁切视图，兼容逐镜头渲染；二选一使用，不能和顶层环境轨道重复叠加。每段必须从 `sourceStart` 读取 `end-time` 秒。非循环素材跨切点的交叉淡化保留原包络：镜头视图的 `fadeInStart` / `fadeOutStart` 为镜头时间中的包络起点，可以是负数；淡化长度仍为 `fadeIn` / `fadeOut`。缺省包络起点分别是 `time` 和 `end-fadeOut`。例如镜头在淡入中间开始，要继续当前淡入进度，不能重新从静音开始。顶层完整轨道没有此裁切复杂性，推荐使用。

第三轮三个多镜头输入与完整原样输出在 `ROUND3_SCENARIO_RESULTS.json`，由 `runRound3Scenarios(library)` 生成，所有动作时间相对所属镜头。原先四场景仍保留于 `SCENARIO_RESULTS.json`。

素材可提供 `suggestedGainDb`，环境计划取它与默认增益中更低者；缺省或非有限值忽略，正数不能提高默认环境增益。例如 -18 LUFS 医院底噪建议 -12 dB，计划音量约为 -30 LUFS（混音后的实测值仍取决于其他轨道）。建议值同步进入整场 `gainAutomation` 和镜头视图。
