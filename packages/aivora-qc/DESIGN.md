# 导出前检查设计与验收

需求来源：本次用户授权；独立、只读分析本地成片 MP4 和可选 UTF-8 SRT，修订范围限本目录和锁文件 importer，不接入 apps，不创建 PR 或合并。

使用 Node 标准库调用系统 ffprobe/ffmpeg，无 npm 依赖、无复制的第三方源码。源码及自编合成素材生成器遵循仓库 Apache-2.0；FFmpeg 为外部运行工具，不打包其二进制。

JSON v1 契约包含媒体时长、检查假设、音频测量和 issues。每项问题包含 id/severity/time/timeLabel/end/type/message/suggestion/action/detail，时间单位秒、从成片起点计。全片响度/峰值问题 time=0、scope=program，不伪造峰值发生位置。失败抛出异常/CLI 非零退出，不把检测失败当作无问题。

黑屏使用 blackdetect（像素黑阈值 .10、黑像素占比 .98），持续 ≥.5 秒；位于片头/片尾且 ≤.5 秒的黑区间豁免，作为短淡入淡出代理，不识别创作意图。静帧使用 freezedetect（噪声 −60dB），≥1 秒；仅整个冻结区间被传入台词区间的并集覆盖时放宽为 ≥2 秒，避免极短台词掩盖长停顿。无声以全声道 ≤−50dB、连续 ≥2 秒判断。音频按首条音轨检测，缺轨仅报告 no_audio；音轨不足时补静音覆盖成片。响度取 loudnorm 输入端 I/TP，−17..−15 LUFS 含边界合格，TP≤−1 dBTP 合格。

SRT 不提供可靠样式坐标。安全区仅按显式参数估算：底部居中，不自动折行，10% 安全边距，底边距12%，字号短边5%，行距1.2，ASCII .6em、其他字符1em。报告保存假设，不声称测量真实烧录字幕。去除基础 HTML/ASS 标签后测量；未知字体、描边、定位、旋转、自动折行会造成差异。单行最多20个全角等效字符（ASCII .5），按 Unicode 码点计。按开始时间稳定排序后比较下一条；相接不算重叠。

测试先用 lavfi 合成运动画面、静帧、黑屏、正弦音和静音；含 EOF、阈值边界、片头片尾、缺音轨、台词覆盖、字幕与错误路径。生成媒体仅存临时目录并清理，不使用真实素材。检测器允许取消与超时，不执行 shell、不覆写输入文件。

修订：工具路径支持显式参数、环境变量、PATH 三级优先级；找不到返回 FFMPEG_NOT_FOUND。测试缺工具才跳过媒体用例，纯逻辑继续。报告普通文案与专业 detail 分开，动作仅供调用方导航，严重程度见 README。
