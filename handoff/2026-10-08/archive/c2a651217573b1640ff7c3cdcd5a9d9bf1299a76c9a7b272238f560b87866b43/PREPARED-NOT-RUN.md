## Dependency-ordered gates

1. **Material and source preflight, read only.** Consume REL02's completed 32-item receipt and MGR04's frozen 185-file source receipt. Rehash all archive bytes, 185 `.py`, SOURCE15, entry, spec, `pyproject.toml`, `uv.lock`, and uv target. Check exact relative paths, regular files, no traversal/symlink, unique names, and no unlisted source input. Record HEAD/status/provenance without mutating checkout. Any missing item, byte/hash mismatch, extra artifact, or authority conflict is RED and stops before extraction.
2. **Python archive and license inspection.** Independently inspect the approved `cpython-3.12.13+20260718-x86_64-pc-windows-msvc-install_only_stripped.tar.gz` SHA-256 `0d422a1439ec308e03f47df551bc30f5994727c456e414b026d202bcda9b7c1c`, 21,932,298 bytes. Inspect tar member paths/types before isolated extraction, reject links/traversal, retain all embedded LICENSE/NOTICE and an extracted-file SHA inventory. Verify extracted Python reports 3.12.13 and PE x64. `install_only_stripped` omits `PYTHON.json`; do not infer a complete license inventory from the live Python installation.
3. **Isolated offline environment.** Use only the newly extracted Python and pinned uv target, absolute paths, isolated cache/TEMP and venv, `UV_OFFLINE=1`, `--offline --no-index --find-links <verified wheelhouse>`. Install an exact 31-version requirements set with dependency resolution enabled. Preserve command, environment allowlist, PID, exit, raw stdout/stderr. Require `uv pip check` success; independent installed distribution name/version set equals the 31 approved wheels, with no extra package or network request. Read actual wheel metadata and license/NOTICE files; keep unresolved classifier-only or archive-bundled license questions explicit. An installed package with a matching version is not a substitute for the pinned wheel archive.
4. **One PyInstaller build.** Only after MGR02 signs the exact packet, build once from a newly copied frozen tree using the frozen spec, isolated `work`, `dist`, cache and TEMP. The spec requires Windows x64, Python 3.12 and PyInstaller 6.22.3 and targets `onefile`, `console=True`, `upx=False`. Preserve full build stdout/stderr, warnings, child PID/exit, module graph and hook output, source and wheel manifests before/after. First RED stops; do not rerun under the same approval.
5. **Static artifact readback.** Require one `aijian-sidecar.exe`, regular file, no unexpected dist files. Record byte count and SHA-256, inspect `MZ`/PE headers and machine `0x8664` (x64), PyInstaller package metadata where available, and independent post-build hash. The build may be marked `EXE_BUILD_ONLY_PASS` only if all prior gates pass and the exact EXE is retained. This does not approve its behavior, installation, release, or redistribution.
